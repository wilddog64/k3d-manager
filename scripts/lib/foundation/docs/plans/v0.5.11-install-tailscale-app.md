## Problem

Plan 7 enrolls three Macs in Tailscale. D1 requires the **Standalone** variant and only one Tailscale on each Mac. The
install step was going to be a hand-typed `brew install --cask tailscale-app` per Mac. `_install_mac_cask` does not fit:
it treats "binary on `PATH`" as installed, but the Standalone app's CLI is not on `PATH`, and on m4 the Homebrew
**formula** puts `/opt/homebrew/bin/tailscale` on `PATH`, so `_install_mac_cask` would report success and install
nothing while the wrong variant stays.

## Fix spec

Add to `scripts/lib/system.sh`, after `_install_vagrant`, two functions (each with a one-line header comment):

`_tailscale_app_bundle_id <app_dir>` prints the bundle ID of `<app_dir>` or nothing, always returns 0:
`plutil -extract CFBundleIdentifier raw -- "${app_dir}/Contents/Info.plist" 2>/dev/null || true`. No `local x="$(...)"`
(SC2155).

`_install_tailscale_app` (no arguments). App path `app_dir="${TAILSCALE_APP_DIR:-/Applications/Tailscale.app}"`
(`TAILSCALE_APP_DIR` exists for tests). Behaviour, in order:

1. Not macOS (`_is_mac` false): `_warn` "Tailscale app installation is supported only on macOS", return 1. No other call.
2. `_command_exist brew` and `brew list --formula tailscale >/dev/null 2>&1` exits 0: `_warn` that the Homebrew
   `tailscale` formula is installed and must be removed first (`brew services stop tailscale; brew uninstall tailscale`),
   return 1. Its output never reaches the caller.
3. `[[ -e "$app_dir" || -L "$app_dir" ]]`: read the ID with `_tailscale_app_bundle_id`, then `case` on it:
   - `io.tailscale.ipn.macsys`: return 0 quietly (idempotent). No install.
   - `io.tailscale.ipn.macos`: `_warn` that the App Store variant is installed and must be removed first (quit Tailscale
     and delete `/Applications/Tailscale.app`), return 1.
   - empty: `_warn` "unreadable bundle ID at <app_dir>", return 1. Anything else: `_warn` naming the ID, return 1.
4. `brew` missing: `_warn` "Homebrew is required to install the Tailscale app", return 1.
5. `_run_command --soft -- brew install --cask tailscale-app || return $?` (brew's exit code passes through).
6. `[[ -d "$app_dir" ]]` and `_tailscale_app_bundle_id` prints exactly `io.tailscale.ipn.macsys`; otherwise `_warn` and
   return 1. On success `_info` "Tailscale (Standalone) installed; open it from Applications to allow its system
   extension and log in".

Safe under a caller running `set -euo pipefail` (every probe guarded). At most 8 lines matching `if` per function
(`AGENT_AUDIT_MAX_IF=8`, the gate that split `_install_istioctl` in v0.5.9); use `case` for the bundle ID. It never
removes anything (removing a conflicting variant is the operator's call), never calls sudo itself (Homebrew's pkg
installer prompts), never opens the app, never runs `tailscale`, logs in or enrolls. Linux is out of scope. If `brew` is
not on `PATH` (a non-login SSH shell), step 2 cannot see the formula; run it from a login shell.

## Rules

- **Stubs** on a scratch bin dir first on `PATH` (then `/usr/bin:/bin`), each logging its argv to one log:
  - `brew`: `list --formula tailscale` prints a Cellar path to stdout and exits 0 when the fixture says the formula is
    installed, else prints `Error: No such keg: /opt/homebrew/Cellar/tailscale` to stderr and exits 1 (captured on m4,
    2026-11-26); `install --cask tailscale-app` creates the app with the fixture's bundle ID (or nothing, or exits 17);
    any other argv exits 99.
  - `plutil`: exits 1 unless argv is exactly `-extract CFBundleIdentifier raw -- <TAILSCALE_APP_DIR>/Contents/Info.plist`;
    prints the bundle ID the fixture wrote, or on a missing file or key prints an error to stderr, nothing to stdout,
    and exits 1 (as real `plutil` does, captured on m4).
  - `sudo`, `open`, `tailscale`: log and exit 0. The `tailscale` stub is on `PATH` only in the formula fixture.
- **Fixture asserts first:** every stub resolves inside the scratch bin dir (`command -v`), and `TAILSCALE_APP_DIR` is
  under `BATS_TEST_TMPDIR`. A control test calls each stub once and sees its log line.
- **M3 without `run`:** `if _install_tailscale_app; then status=0; else status=$?; fi` (as `system.bats` does for the VM
  casks), assert `status` is 17, and that the next line of the test runs. One test runs the M1 path under
  `bash -c 'set -euo pipefail; source ...; _install_tailscale_app'`.
- No real `brew` in tests. Do not change `_install_mac_cask` or any other installer.
- **Gates:** `make bats`, `make shellcheck-lib`, `shellcheck scripts/tests/lib/system.bats`,
  `AGENT_AUDIT_MAX_IF=8 bash scripts/lib/agent_rigor.sh scripts/lib/system.sh`. (`make test` and `make lint` cover ACG
  only.) Leave the changes uncommitted; Claude reviews and commits.
