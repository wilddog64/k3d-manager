# Bugfix: v1.23.0 — TrivyCriticalVulnerabilityDetected pages with an empty app name

**Branch:** `k3d-manager-v1.23.0`
**Files:** `scripts/etc/argocd/platform-ops/prometheusrule.yaml`, `scripts/etc/argocd/platform-ops/vulnerability-inventory-exporter.yaml`
**Status:** QUEUED — ready for Codex. Independent of the Grafana rotation bugfix (different files, separate commit).
**Severity:** medium — recurring false/unactionable page; noise erodes trust in the CVE alert.

---

## Problem

Recurring Slack alert `:mag: TrivyCriticalVulnerabilityDetected — `` `` (empty app name). The alert's
Slack template renders `.Labels.app`, and the rule sets `app: "{{ $labels.image_repository }}"`
(`prometheusrule.yaml:77`). So an **empty `app` means an empty `image_repository`** — NOT a missing
workload label.

`image_repository` is emitted by the custom `vulnerability-inventory-exporter` from
`report.report.artifact.repository` (`vulnerability-inventory-exporter.yaml:165` hub / `:178`
app-cluster). When Trivy scans a transient/ephemeral workload (finished Job/CronJob pods —
`cve-auto`, `cve-remediation-verify` every 5m, `acg-expiry-check`, `scan-vulnerabilityreport`, etc.)
it can produce a VulnerabilityReport whose `artifact.repository` is empty. If that report carries a
CRITICAL finding and persists ≥15m (`for: 15m`), the alert fires with `image_repository=""` →
`app=""` → the empty-name page.

**Root cause:** the alert and the exporter both emit/alert on series with an empty
`image_repository`. An image with no repository name is unidentifiable and unremediable, so alerting
on it is pure noise.

**NOT the cause (correcting the auto-diagnosis that shipped with the alert):** the notification
claimed the ephemeral pods "lack a standard app label" so the app interpolates empty, and proposed
`OPERATOR_SCAN_JOB_TTL` + `ttlSecondsAfterFinished`. That mechanism is wrong (`app` = `image_repository`,
not a pod label), and TTL cleanup only thins the ephemeral-report population — it does not prevent an
empty-repository CRITICAL from paging. TTL hygiene is worth doing separately but is **out of scope**
here.

## Fix

### Change 1 — alert never fires on an empty image (`prometheusrule.yaml`)

**Exact old block (line 67):**

```yaml
              trivy_vulnerability_inventory{severity="CRITICAL"}
```

**Exact new block:**

```yaml
              trivy_vulnerability_inventory{severity="CRITICAL", image_repository!=""}
```

### Change 2 — exporter skips reports with an empty repository (`vulnerability-inventory-exporter.yaml`)

Prevents the blank series at the source (also removes blank dashboard rows). Two loops — hub and
app-cluster. Insert a guard immediately after each `meta, artifact = …` line.

**2a — hub loop. Exact old block (lines 162–164):**

```python
            for report in reports:
                meta, artifact = report.get("metadata", {}), report.get("report", {}).get("artifact", {})
                for finding in report.get("report", {}).get("vulnerabilities", []):
```

**Exact new block:**

```python
            for report in reports:
                meta, artifact = report.get("metadata", {}), report.get("report", {}).get("artifact", {})
                if not artifact.get("repository"):
                    continue
                for finding in report.get("report", {}).get("vulnerabilities", []):
```

**2b — app-cluster loop. Exact old block (lines 175–177):**

```python
                for report in app_reports:
                    meta, artifact = report.get("metadata", {}), report.get("report", {}).get("artifact", {})
                    for finding in report.get("report", {}).get("vulnerabilities", []):
```

**Exact new block:**

```python
                for report in app_reports:
                    meta, artifact = report.get("metadata", {}), report.get("report", {}).get("artifact", {})
                    if not artifact.get("repository"):
                        continue
                    for finding in report.get("report", {}).get("vulnerabilities", []):
```

> Preserve the exact surrounding indentation (hub loop body at 16 spaces, app-cluster loop body at
> 20 spaces). The `exporter.py` block is embedded YAML `data:` — keep it valid YAML.
