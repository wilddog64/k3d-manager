# Bugfix: v1.24.0 — ArgoCD credential rotator fails live (bcrypt EOF + Password prefix + Istio sidecar)

**Branch:** `k3d-manager-v1.24.0`
**Files:** `scripts/etc/argocd/platform-ops/argocd-credential-rotator.yaml`, `scripts/tests/plugins/argocd.bats`,
`scripts/plugins/observability.sh`

> Scope note: also covers a fourth defect found in the same E live-verify pass — the **Prometheus
> host-side rotator's launchd install points at a nonexistent binary** (`bin/k3d-manager`). See Change 4.

---

## Problem

The ArgoCD monthly credential rotator (shipped in `3db193cb`, E workstream) **fails on every run**.
Found during the E live one-shot verify — three independent defects, none caught by the structural
BATS test:

1. **`fatal EOF`, exit 20 (the visible failure).** The bcrypt step feeds the password with
   `printf '%s' "$new"` — **no trailing newline**. `argocd account bcrypt` reads a line from stdin and
   hits EOF before a complete line → `{"level":"fatal","msg":"EOF"}`, exit 20. The script aborts under
   `set -eu` *before* any Vault write or `argocd-secret` patch (so live state was never mutated —
   verified `argocd-secret.admin.passwordMtime` unchanged across the failed runs).

2. **`Password: ` prompt captured into the hash (latent, worse).** Even with a newline,
   `argocd account bcrypt` prints its `Password: ` prompt to **stdout** (stderr is empty), so
   `new_bcrypt="$(… argocd account bcrypt)"` captures `Password: $2a$10$…` — a **malformed hash**. Had
   bug 1 not aborted first, this would have written a corrupt bcrypt to `argocd-secret.admin.password`
   and **broken ArgoCD admin login**.

3. **Istio sidecar deadlock.** The CronJob runs in namespace `cicd`, which has
   `istio-injection=enabled`. The pod gets an `istio-proxy` sidecar; the `rotate` container races the
   proxy (egress to Vault before the proxy is ready) and the proxy never lets the Job complete →
   `BackoffLimitExceeded`. (The Grafana rotator works because it lives in `platform-ops`, which has no
   injection.)

**Root cause:** the application step was written from the spec's illustrative snippet
(`printf '%s' … | argocd account bcrypt`) and never run live; `argocd account bcrypt` in
`quay.io/argoproj/argocd` requires a newline-terminated stdin line and emits a `Password: ` prompt on
stdout, and the `cicd` namespace injects a sidecar into Jobs.

---

## Reproduction

```bash
kubectl -n cicd create job t --from=cronjob/argocd-credential-rotator   # → BackoffLimitExceeded (sidecar)
# with sidecar disabled:
printf '%s' pw | kubectl -n cicd exec -i deploy/argocd-server -- argocd account bcrypt   # → fatal EOF, exit 20
printf '%s\n' pw | kubectl -n cicd exec -i deploy/argocd-server -- argocd account bcrypt # → "Password: $2a$10$…"  (prefix on stdout)
```

---

## Fix

### Change 1 — exclude the rotator pod from the Istio sidecar mesh

**Exact old block (pod template metadata):**
```yaml
      template:
        metadata:
          labels:
            app.kubernetes.io/name: argocd-credential-rotator
        spec:
```

**Exact new block:**
```yaml
      template:
        metadata:
          labels:
            app.kubernetes.io/name: argocd-credential-rotator
          annotations:
            sidecar.istio.io/inject: "false"
        spec:
```

### Change 2 — newline-terminate stdin and strip the `Password: ` prompt

**Exact old block (the `new_bcrypt=` line):**
```sh
                  new_bcrypt="$(printf '%s' "$new" | kubectl exec -i -n cicd deploy/argocd-server -- argocd account bcrypt)"
```

**Exact new block:**
```sh
                  new_bcrypt="$(printf '%s\n' "$new" | kubectl exec -i -n cicd deploy/argocd-server -- argocd account bcrypt | sed 's/^Password: //')"
```

Keep stdin (never `--password` — that leaks the secret into the `kubectl exec` argv / OWASP A02).

### Change 4 — `observability.sh`: Prometheus rotator launchd install points at a real binary

`_observability_install_prometheus_rotator` templates the plist's `{{K3D_MANAGER_PATH}}` to
`${SCRIPT_DIR}/../bin/k3d-manager`, but there is **no `bin/k3d-manager`** — the dispatcher is
`scripts/k3d-manager` (i.e. `${SCRIPT_DIR}/k3d-manager`). The monthly launchd job would exec a missing
file and fail every run.

**Exact old block:**
```bash
    -e "s|{{K3D_MANAGER_PATH}}|${SCRIPT_DIR}/../bin/k3d-manager|g" \
```

**Exact new block:**
```bash
    -e "s|{{K3D_MANAGER_PATH}}|${SCRIPT_DIR}/k3d-manager|g" \
```

### Change 3 — `argocd.bats`: assert the runtime-correct bcrypt invocation

Extend the rotator structural test to require the newline-fed pipe and the prompt strip: the
`argocd account bcrypt` invocation must be preceded by `printf '%s\n'` and followed by
`sed 's/^Password: //'` (guards against a regression back to the EOF / prefix-in-hash bugs). Add a
check that the pod template carries `sidecar.istio.io/inject: "false"`.
