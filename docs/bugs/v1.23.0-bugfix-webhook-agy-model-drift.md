# Bugfix: v1.23.0 — webhook alert analysis uses retired agy model `gemini-2.5-flash`

**Branch:** `k3d-manager-v1.23.0`
**Files:** `bin/k3dm-webhook`
**Status:** QUEUED. Live-triaged 2026-08-08 (recurring bad Slack notification).
**Severity:** medium — every analyzed alert (incl. TrivyCriticalVulnerabilityDetected) posts an agy error instead of analysis.

---

## Problem

Slack alerts routed through Alertmanager render an inline agy error instead of AI analysis:

```
TrivyCriticalVulnerabilityDetected — ``
Error: invalid model selection (--model "gemini-2.5-flash" --effort ""):
model gemini-2.5-flash is not recognized as a known model or custom model in settings
```

Path: Alertmanager `k3dm-analyze` receiver (`alertmanager-config.yaml:35`) →
`https://webhook.3ai-talk.org/api/v1/analyze` → the webhook runs
`agy --model GEMINI_MODEL` (`bin/k3dm-webhook:1162`), where
`GEMINI_MODEL = os.environ.get("K3DM_ANALYSIS_MODEL", "gemini-2.5-flash")` (`:211`).

**Root cause:** agy retired the `gemini-2.5-flash` model ID. Current IDs encode effort (verified via
`agy models` 2026-08-08): `gemini-3.6-flash-{high,medium,low}`, `gemini-3.5-flash-{high,medium,low}`,
`gemini-3.1-pro-{high,low}`, `claude-sonnet-4-6`, `claude-opus-4-6-thinking`, `gpt-oss-120b-medium`.
The webhook default is stale, and the live env does not override `K3DM_ANALYSIS_MODEL`, so every
alert analysis fails at model selection. (`--effort ""` is agy echoing its own parsed args, not passed
by the webhook.)

> Out of scope here: `scripts/plugins/gemini.sh` (`_GEMINI_MODELS` = 2.5/2.0/1.5-flash) and
> `scripts/tests/lib/antigravity.bats` carry the same drift on the **browser-automation** path (not
> this alert). Separate follow-up — the bats assertions are coupled to the model chain.

---

## Fix — default to a current agy model ID

**File:** `bin/k3dm-webhook`

**Exact old block (line 211):**

```python
GEMINI_MODEL = os.environ.get("K3DM_ANALYSIS_MODEL", "gemini-2.5-flash")
```

**Exact new block:**

```python
GEMINI_MODEL = os.environ.get("K3DM_ANALYSIS_MODEL", "gemini-3.5-flash-medium")
```

`gemini-3.5-flash-medium` is a current, valid ID (flash tier — fast/cheap for alert triage; medium
effort). `K3DM_ANALYSIS_MODEL` still overrides for anyone who wants a different model.
