# Bugfix: v1.23.0 — webhook rate-limit ordering + Content-Length guard

**Branch:** `k3d-manager-v1.23.0`
**Files:** `bin/k3dm-webhook`, `scripts/tests/bin/webhook_request_hardening.py`

---

## Problem

Two request-handling regressions in the webhook server (`bin/k3dm-webhook`):

1. **Pre-auth rate limiting.** `do_POST` (line 3018) and `do_GET` (line 3386) call
   `_rate_limited(...)` **before** the signature/token check. The limiter uses a single global
   fixed-window bucket per channel (`_rate_hits["slack"]` / `_rate_hits["api"]`, 60/min). An
   **unauthenticated** burst therefore consumes the same bucket the one legitimate authenticated
   caller needs, and can 429 real traffic for the rest of the window.
2. **Unguarded `Content-Length`.** `do_POST` at lines 3022 (slack) and 3114 (api) does
   `int(self.headers.get("Content-Length", 0))` with no guard. A non-integer header raises
   `ValueError` on attacker-controlled input — the request thread aborts with a traceback and the
   caller gets a dropped connection / 500 instead of a clean 400.

**Root cause:** the limiter is placed ahead of the only trustworthy identity check (the Slack
signature / bearer token — the server binds `127.0.0.1` behind a tunnel, so `client_address` is
always localhost and the `X-K3DM-Actor` header is spoofable; auth is the *only* real gate), and
`Content-Length` is parsed with a bare `int()` that trusts the header is numeric.

---

## Reproduction

```bash
# Finding 1 — unauthenticated flood starves the authenticated caller
for i in $(seq 1 61); do curl -s -o /dev/null http://127.0.0.1:7443/api/v1/health; done
# 61st+ authenticated GET now returns 429 even with a valid token, until the window resets.

# Finding 2 — malformed Content-Length aborts the handler
curl -s -X POST http://127.0.0.1:7443/api/v1/cluster \
  -H "Authorization: Bearer $TOKEN" -H "Content-Length: abc" --data '{}'
# Expected: HTTP 400 {"error":"invalid content-length"}
# Actual:   connection dropped / traceback in server log (uncaught ValueError)
```

## Fix

### Change 1 — `bin/k3dm-webhook`: add a `Content-Length` parse helper

Add a module-level helper immediately after `_request_source_command` (ends at the line
`return source_command or "direct-api"`).

**Exact old block (lines 318–321):**

```python
def _request_source_command(headers):
    source_command = (headers.get("X-K3DM-Source-Command", "") or "").strip()
    return source_command or "direct-api"
```

**Exact new block:**

```python
def _request_source_command(headers):
    source_command = (headers.get("X-K3DM-Source-Command", "") or "").strip()
    return source_command or "direct-api"


def _content_length(headers):
    """Parse Content-Length as a non-negative int; return None if malformed."""
    raw = headers.get("Content-Length", "0")
    try:
        length = int(raw)
    except (TypeError, ValueError):
        return None
    return length if length >= 0 else None
```

### Change 2 — `bin/k3dm-webhook`: `do_POST` — limiter after signature verify + guard slack `Content-Length`

**Exact old block (lines 3017–3033):**

```python
    def do_POST(self):
        if _rate_limited("slack" if self.path == "/slack/events" else "api"):
            self._json(429, {"error": "rate limited"})
            return
        if self.path == "/slack/events":
            length = int(self.headers.get("Content-Length", 0))
            raw_body = self.rfile.read(min(length, MAX_BODY))
            timestamp = self.headers.get("X-Slack-Request-Timestamp", "0")
            signature = self.headers.get("X-Slack-Signature", "")
            if not _verify_slack_signature(raw_body, timestamp, signature):
                self._json(401, {"error": "invalid signature"})
                return
```

**Exact new block:**

```python
    def do_POST(self):
        if self.path == "/slack/events":
            length = _content_length(self.headers)
            if length is None:
                self._json(400, {"error": "invalid content-length"})
                return
            raw_body = self.rfile.read(min(length, MAX_BODY))
            timestamp = self.headers.get("X-Slack-Request-Timestamp", "0")
            signature = self.headers.get("X-Slack-Signature", "")
            if not _verify_slack_signature(raw_body, timestamp, signature):
                self._json(401, {"error": "invalid signature"})
                return
            if _rate_limited("slack"):
                self._json(429, {"error": "rate limited"})
                return
```

### Change 5 — new regression test `scripts/tests/bin/webhook_request_hardening.py`

Create this file (new file — full content):

```python
#!/usr/bin/env python3
"""Regression tests for k3dm-webhook request hardening.

Covers:
  * _content_length: malformed / missing / negative header handling (Finding 2)
  * _rate_limited: fixed-window enforcement still fires (Finding 1 sanity)
  * do_GET: rate limiter runs AFTER auth, so unauthenticated requests do not
    consume the shared bucket (Finding 1 ordering)
"""
import importlib.util
import unittest
from pathlib import Path

_WEBHOOK = Path(__file__).resolve().parents[3] / "bin" / "k3dm-webhook"
_spec = importlib.util.spec_from_file_location("k3dm_webhook", _WEBHOOK)
wh = importlib.util.module_from_spec(_spec)
_spec.loader.exec_module(wh)


class ContentLengthTests(unittest.TestCase):
    def test_valid(self):
        self.assertEqual(wh._content_length({"Content-Length": "42"}), 42)

    def test_missing_defaults_zero(self):
        self.assertEqual(wh._content_length({}), 0)

    def test_non_integer_returns_none(self):
        self.assertIsNone(wh._content_length({"Content-Length": "abc"}))

    def test_negative_returns_none(self):
        self.assertIsNone(wh._content_length({"Content-Length": "-1"}))


class RateLimitTests(unittest.TestCase):
    def setUp(self):
        wh._rate_hits.clear()

    def test_fixed_window_enforced(self):
        for _ in range(wh._RATE_MAX_DEFAULT):
            self.assertFalse(wh._rate_limited("api"))
        self.assertTrue(wh._rate_limited("api"))

    def test_unauthenticated_get_does_not_consume_bucket(self):
        h = wh._Handler.__new__(wh._Handler)
        responses = []
        h._json = lambda code, body: responses.append((code, body))
        h._auth = lambda: False
        h.path = "/api/v1/health"
        h.headers = {}
        for _ in range(wh._RATE_MAX_DEFAULT * 3):
            responses.clear()
            h.do_GET()
            self.assertEqual(responses[0][0], 401)
        self.assertEqual(wh._rate_hits.get("api", (0, 0))[1], 0)


if __name__ == "__main__":
    unittest.main()
```
