## Problem

Commit `84a60ef5` ("fix(run-dir): move debug artifacts out of tmp") added
`_acg_watch_retarget_logs`, which rewrites the acg-watch launchd plist so its
`StandardOutPath` / `StandardErrorPath` point at
`~/.local/share/k3d-manager/run` instead of `/tmp`. But the wrapper calls it
**after** the foundation `acg_watch_start` has already `launchctl load`ed the
agent:

- Foundation `acg_watch_start` (`scripts/lib/foundation/scripts/lib/acg/acg.sh`
  lines ~562–570) writes the plist with the `/tmp` paths, then runs
  `launchctl load "${_ACG_WATCH_PLIST_PATH}"`.
- The consumer wrapper (`scripts/plugins/acg.sh:84`) then calls
  `_acg_watch_retarget_logs`, which edits the plist file on disk.

Editing a plist file has **no effect on an already-loaded launchd agent** — the
paths are read at load time. The running watcher keeps writing to
`/tmp/k3d-manager-acg-watch.{out,err}`, and each subsequent `acg_watch_start`
regenerates the `/tmp` plist before loading again, so the retarget is
effectively a no-op for the live agent. The `_info` line claiming logs are
"redirected to …/run/…" is therefore inaccurate.

A secondary hardening issue: `bin/k3dm-webhook` `_posix_spawn_capture` now writes
its transcript via `NamedTemporaryFile(dir=str(RUN_DIR))`, but `RUN_DIR.mkdir(...)`
runs only under `if __name__ == "__main__"`. The running server creates it at
startup, but any direct import/call of `_posix_spawn_capture` (or the run dir
being removed mid-session) raises `FileNotFoundError` where the old code used the
always-present default temp dir.

**Root cause:** the plist is retargeted after the launchd agent is already
loaded, and nothing reloads the agent afterward, so the new log paths are never
applied to the running process.

## Reproduction

```bash
# macOS, after a run-dir-enabled build:
acg_watch_start "https://example.com/sandbox"
launchctl list com.k3d-manager.acg-watch >/dev/null && \
  /usr/libexec/PlistBuddy -c 'Print :StandardErrorPath' \
    ~/Library/LaunchAgents/com.k3d-manager.acg-watch.plist
# plist file now shows: ~/.local/share/k3d-manager/run/k3d-manager-acg-watch.err
# but the *running* agent still writes to /tmp/k3d-manager-acg-watch.err
# (confirm by triggering the watcher and observing where the log grows)
```

## Fix

### Change 1 — `scripts/plugins/acg.sh`: reload the agent after retargeting

Modify `_acg_watch_retarget_logs` only. Add the launchd label as a local, then
reload the agent after the plist is rewritten so the new paths take effect. Do
not add inline comments.

**Exact old block (lines ~45–73):**

```bash
_acg_watch_retarget_logs() {
  local run_dir plist_path out_path err_path
  run_dir="${K3DM_RUN_DIR:-${HOME}/.local/share/k3d-manager/run}"
  plist_path="${_ACG_WATCH_PLIST_PATH:-${HOME}/Library/LaunchAgents/com.k3d-manager.acg-watch.plist}"
  out_path="${run_dir}/k3d-manager-acg-watch.out"
  err_path="${run_dir}/k3d-manager-acg-watch.err"

  [[ -f "${plist_path}" ]] || return 0
  mkdir -p "${run_dir}"

  python3 - "${plist_path}" "${out_path}" "${err_path}" <<'PY'
import plistlib
import sys
from pathlib import Path

plist_path = Path(sys.argv[1])
out_path = sys.argv[2]
err_path = sys.argv[3]

with plist_path.open('rb') as handle:
    data = plistlib.load(handle)

data["StandardOutPath"] = out_path
data["StandardErrorPath"] = err_path

with plist_path.open('wb') as handle:
    plistlib.dump(data, handle, sort_keys=False)
PY
}
```

**Exact new block:**

```bash
_acg_watch_retarget_logs() {
  local run_dir plist_path out_path err_path label
  run_dir="${K3DM_RUN_DIR:-${HOME}/.local/share/k3d-manager/run}"
  plist_path="${_ACG_WATCH_PLIST_PATH:-${HOME}/Library/LaunchAgents/com.k3d-manager.acg-watch.plist}"
  label="${_ACG_WATCH_LAUNCHD_LABEL:-com.k3d-manager.acg-watch}"
  out_path="${run_dir}/k3d-manager-acg-watch.out"
  err_path="${run_dir}/k3d-manager-acg-watch.err"

  [[ -f "${plist_path}" ]] || return 0
  mkdir -p "${run_dir}"

  python3 - "${plist_path}" "${out_path}" "${err_path}" <<'PY'
import plistlib
import sys
from pathlib import Path

plist_path = Path(sys.argv[1])
out_path = sys.argv[2]
err_path = sys.argv[3]

with plist_path.open('rb') as handle:
    data = plistlib.load(handle)

data["StandardOutPath"] = out_path
data["StandardErrorPath"] = err_path

with plist_path.open('wb') as handle:
    plistlib.dump(data, handle, sort_keys=False)
PY

  if command -v launchctl >/dev/null 2>&1 && launchctl list "${label}" >/dev/null 2>&1; then
    launchctl unload "${plist_path}" 2>/dev/null || true
    launchctl load "${plist_path}" 2>/dev/null || true
  fi
}
```

Leave `acg_watch_start` (lines ~84–88) unchanged — once the reload lands, its
existing `_info "… logs redirected to …"` message is accurate.

### Change 2 — `bin/k3dm-webhook`: ensure the run dir exists before capture

In `_posix_spawn_capture`, create the run dir before opening the temp file so the
function is self-sufficient regardless of the `__main__` startup path.

**Exact old block (lines ~1182–1186):**

```python
    try:
        with _tmp.NamedTemporaryFile(
            prefix="k3dm-ask-", suffix=".out", delete=False, mode="w", dir=str(RUN_DIR)
        ) as _f:
            tmp_path = _f.name
```

**Exact new block:**

```python
    try:
        RUN_DIR.mkdir(parents=True, exist_ok=True)
        with _tmp.NamedTemporaryFile(
            prefix="k3dm-ask-", suffix=".out", delete=False, mode="w", dir=str(RUN_DIR)
        ) as _f:
            tmp_path = _f.name
```

### Change 3 — `scripts/tests/lib/acg.bats`: replace the retarget test with a reload-aware one

The current test stubs `__acg_stub_acg_watch_start` **without** `launchctl load`,
so it validates only the plist rewrite and cannot catch the load-ordering bug.
Replace it with a test that simulates the foundation load, uses a fake
`launchctl` on `PATH`, and asserts the agent is (re)loaded **after** the plist is
retargeted. It also points `_ACG_WATCH_PLIST_PATH` at a temp file so it never
touches the real LaunchAgents plist.

**Exact old block (lines ~188–218):**

```bash
@test "acg_watch_start rewrites generated launchd logs into the k3d-manager run dir" {
  local plist_path
  export K3DM_RUN_DIR="${HOME}/.local/share/k3d-manager/run"
  plist_path="${HOME}/Library/LaunchAgents/com.k3d-manager.acg-watch.plist"

  __acg_stub_acg_watch_start() {
    mkdir -p "$(dirname "${plist_path}")"
    cat > "${plist_path}" <<'PLIST'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>StandardOutPath</key>
  <string>/tmp/k3d-manager-acg-watch.out</string>
  <key>StandardErrorPath</key>
  <string>/tmp/k3d-manager-acg-watch.err</string>
</dict>
</plist>
PLIST
  }
  export -f __acg_stub_acg_watch_start

  run acg_watch_start "https://example.com/sandbox"
  [ "$status" -eq 0 ]

  run grep -F -- "${K3DM_RUN_DIR}/k3d-manager-acg-watch.out" "${plist_path}"
  [ "$status" -eq 0 ]

  run grep -F -- "${K3DM_RUN_DIR}/k3d-manager-acg-watch.err" "${plist_path}"
  [ "$status" -eq 0 ]
}
```

**Exact new block:**

```bash
@test "acg_watch_start reloads the agent so retargeted run-dir logs take effect" {
  local old_path fake_bin capture plist_path
  export K3DM_RUN_DIR="${BATS_TEST_TMPDIR}/run"
  export _ACG_WATCH_PLIST_PATH="${BATS_TEST_TMPDIR}/com.k3d-manager.acg-watch.plist"
  export _ACG_WATCH_LAUNCHD_LABEL="com.k3d-manager.acg-watch"
  plist_path="${_ACG_WATCH_PLIST_PATH}"
  fake_bin="${BATS_TEST_TMPDIR}/bin"
  capture="${BATS_TEST_TMPDIR}/launchctl-loads.log"
  mkdir -p "${fake_bin}" "${K3DM_RUN_DIR}"

  cat > "${fake_bin}/launchctl" <<EOF
#!/usr/bin/env bash
if [ "\$1" = "list" ]; then exit 0; fi
if [ "\$1" = "load" ]; then grep -F 'k3d-manager-acg-watch.err' "\$2" >> "${capture}" || true; fi
exit 0
EOF
  chmod +x "${fake_bin}/launchctl"

  __acg_stub_acg_watch_start() {
    cat > "${_ACG_WATCH_PLIST_PATH}" <<'PLIST'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>StandardOutPath</key>
  <string>/tmp/k3d-manager-acg-watch.out</string>
  <key>StandardErrorPath</key>
  <string>/tmp/k3d-manager-acg-watch.err</string>
</dict>
</plist>
PLIST
    launchctl load "${_ACG_WATCH_PLIST_PATH}"
  }
  export -f __acg_stub_acg_watch_start

  old_path="${PATH}"
  export PATH="${fake_bin}:${PATH}"
  run acg_watch_start "https://example.com/sandbox"
  export PATH="${old_path}"
  [ "$status" -eq 0 ]

  run grep -F -- "${K3DM_RUN_DIR}/k3d-manager-acg-watch.err" "${plist_path}"
  [ "$status" -eq 0 ]

  run tail -n 1 "${capture}"
  [[ "${output}" == *"${K3DM_RUN_DIR}/k3d-manager-acg-watch.err"* ]]
}
```

> Why this catches the bug: the fake `launchctl` records the `StandardErrorPath`
> present in the plist at each `load`. The stub load records the `/tmp` path; the
> wrapper's reload (only present with the fix) records the run-dir path. The
> `tail -n 1` assertion fails on the unpatched code because the last (only) load
> saw `/tmp`.

### Change 4 — `scripts/tests/lib/webhook.bats`: assert the run-dir mkdir

Add one test (place it next to the existing
`"webhook ask subprocess captures transcripts in the k3d-manager run dir"` test):

```bash
@test "webhook ask subprocess ensures the run dir exists before capturing" {
    run grep -F -- 'RUN_DIR.mkdir(parents=True, exist_ok=True)' "${BATS_TEST_DIRNAME}/../../../bin/k3dm-webhook"
    [ "$status" -eq 0 ]
}
```
