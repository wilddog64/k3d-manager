# Bugfix: v1.24.0 — Prometheus basic-auth seeds the weak `admin/password` default

**Branch:** `k3d-manager-v1.24.0`
**Files:** `scripts/plugins/observability.sh`, `scripts/tests/lib/observability.bats`

---

## Problem

`_prometheus_acg_web_config_secret` (`scripts/plugins/observability.sh`) seeds the Prometheus
basic-auth credential with a **hardcoded weak default**: `_prom_password="${PROM_ADMIN_PASSWORD:-password}"`
and a precomputed `_default_bcrypt_hash` that is literally `bcrypt('password')`. This credential is
applied to the **ACG sandbox** Prometheus web-config (`monitoring/prometheus-web-config`), which is a
public endpoint.

**Confirmed live (2026-08-10):** hub Vault `secret/k3d-manager/prometheus-basic-auth` = `admin` / `password`
(8 chars), and `password_bcrypt` equals the weak default hash. Because the seed logic only generates when
the Vault value is **empty**, the weak value persists forever once written — it is never rotated or
upgraded, and every ACG sandbox reads it back.

**Root cause:** the seed path uses a literal `'password'` fallback and a constant bcrypt hash instead of
generating a strong random credential; and it never detects/replaces the known-weak value.

> **Scope note.** The hub Prometheus enforces **no** basic-auth (empty `web-config.yaml`, no `.spec.web`;
> access is a localhost port-forward), so the exposure is the ACG sandbox path only. This bugfix removes
> the weak default at the root; recurring rotation is handled separately in
> `docs/plans/v1.24.0-credential-rotation-automation.md` (E).

---

## Reproduction

```bash
VT=$(kubectl get secret vault-root -n secrets -o jsonpath='{.data.root_token}' | base64 -d)
kubectl exec -n secrets vault-0 -- sh -c "VAULT_TOKEN=$VT vault kv get -format=json secret/k3d-manager/prometheus-basic-auth" \
  | python3 -c "import json,sys; d=json.load(sys.stdin)['data']['data']; print('weak:', d['password']=='password')"
# -> weak: True
```

## Fix

### Change 1 — `observability.sh`: add a strong-credential generator (htpasswd, stdin-fed)

Add this helper directly **above** `_prometheus_acg_web_config_secret` (before line 511). `htpasswd -i`
reads the password from **stdin**, so it never appears in `argv`/process listings (OWASP A02 secret hygiene).

**Exact new block:**

```bash
# Known-weak legacy value: bcrypt('password'). Detected + replaced on sight.
_PROM_WEAK_BCRYPT='$2a$12$NqL.y.Z1.h.1.E.1.p.9.Q.2.a.7.I.3.Z.7.d.3.Q.2.v.0.K.2.x.6'

function _observability_generate_prometheus_basic_auth() {
  # Sets _PROM_BASIC_AUTH_PASSWORD + _PROM_BASIC_AUTH_BCRYPT to a fresh strong credential.
  # bcrypt via htpasswd stdin (-i) so the plaintext never lands in argv or logs.
  if ! command -v htpasswd >/dev/null 2>&1; then
    _err "[observability] htpasswd required to generate Prometheus basic-auth (install httpd-tools/apache2-utils)"
    return 1
  fi
  _PROM_BASIC_AUTH_PASSWORD="${PROM_ADMIN_PASSWORD:-$(LC_ALL=C tr -dc 'A-Za-z0-9' </dev/urandom | head -c 32)}"
  if [[ "${_PROM_BASIC_AUTH_PASSWORD}" == "password" ]]; then
    _err "[observability] refusing to seed Prometheus basic-auth with the weak literal 'password'"
    return 1
  fi
  _PROM_BASIC_AUTH_BCRYPT="$(printf '%s' "${_PROM_BASIC_AUTH_PASSWORD}" | htpasswd -niBC 12 admin | cut -d: -f2-)"
  [[ -n "${_PROM_BASIC_AUTH_BCRYPT}" ]] || { _err "[observability] failed to generate Prometheus bcrypt"; return 1; }
}
```

### Change 2 — `observability.sh`: detect + replace the weak value on read

**Exact old block (lines 524–530):**

```bash
  local _prom_creds
  if ! _prom_creds=$(curl -sf \
      --header "@${_vault_hdr}" \
      "${_vault_addr}/v1/secret/data/k3d-manager/prometheus-basic-auth" 2>/dev/null \
      | python3 -c "import json,sys; d=json.load(sys.stdin)['data']['data']; \
        print(d['user']+'|'+d['password_bcrypt'])" 2>/dev/null); then
    _prom_creds=""
  fi
```

**Exact new block:**

```bash
  local _prom_creds
  if ! _prom_creds=$(curl -sf \
      --header "@${_vault_hdr}" \
      "${_vault_addr}/v1/secret/data/k3d-manager/prometheus-basic-auth" 2>/dev/null \
      | python3 -c "import json,sys; d=json.load(sys.stdin)['data']['data']; \
        print(d['user']+'|'+d['password_bcrypt'])" 2>/dev/null); then
    _prom_creds=""
  fi
  if [[ "${_prom_creds#*|}" == "${_PROM_WEAK_BCRYPT}" ]]; then
    _warn "[observability] Prometheus basic-auth is the weak 'password' default — regenerating"
    _prom_creds=""
  fi
```

### Change 3 — `observability.sh`: use the generator instead of the weak default

**Exact old block (lines 531–536):**

```bash
  if [[ -z "${_prom_creds}" ]]; then
    local _default_bcrypt_hash="\$2a\$12\$NqL.y.Z1.h.1.E.1.p.9.Q.2.a.7.I.3.Z.7.d.3.Q.2.v.0.K.2.x.6" # bcrypt hash for 'password'
    local _prom_password="${PROM_ADMIN_PASSWORD:-password}"
    local _prom_payload

```

**Exact new block:**

```bash
  if [[ -z "${_prom_creds}" ]]; then
    _observability_generate_prometheus_basic_auth || return 1

    _prom_payload=$(_observability_prometheus_vault_payload "${_PROM_BASIC_AUTH_PASSWORD}" "${_PROM_BASIC_AUTH_BCRYPT}") || _prom_payload=""
```

## One-time live rotation (release step, not part of the commit)

The self-heal (Change 2) replaces the live weak value automatically on the next ACG deploy. To close it
immediately without waiting, re-run the seed path (Claude-owned ops), or delete the Vault key so the next
deploy regenerates:

```bash
VT=$(kubectl get secret vault-root -n secrets -o jsonpath='{.data.root_token}' | base64 -d)
kubectl exec -i -n secrets vault-0 -- sh -c "VAULT_TOKEN=$VT vault kv delete secret/k3d-manager/prometheus-basic-auth"
```
