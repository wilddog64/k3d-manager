# Bug: v1.40.0 PR CI is red: new bare `!` assertions and a stale `/ask-docs` usage string

**Filed:** 2026-10-02
**Status:** OPEN
**Branch:** `k3d-manager-v1.40.0`
**Found by:** CI `lint` job on PR #134 (run `37050330160`), reproduced locally with `bats`
**Related:** `docs/bugs/2026-09-14-bats-bare-negation-assertions-never-fail.md` (third occurrence)

## Symptom

`make test` in CI fails two tests:

```
not ok 58 no bare '! cmd' assertions in BATS suites (set -e ignores them)
# (in test file scripts/tests/lib/bats_negation_lint.bats, line 6)
not ok 1148 ask-docs relay validates text and sends its own endpoint
# (in test file scripts/tests/plugins/slack_ask_docs.bats, line 16)
```

## Root cause

1. **Bare negations.** Nine lines added on this branch begin with `! `, and `bats_negation_lint.bats` rejects
   them all. The six `keycloak.bats` lines end in `|| false`, so they do fail correctly, but the lint does not
   accept that form. The convention set by the 2026-09-14 bug is `run <cmd>` followed by `[ "$status" -ne 0 ]`.
2. **Stale string.** `61d6d3fb` added `--sources` and changed the relay's usage reply to
   `Usage: /ask-docs [--sources] <question>` (`workers/slack-relay/index.js:475`). `slack_ask_docs.bats:15`
   still greps for the old `Usage: /ask-docs <question>`.

## Fix

### S1: `scripts/tests/plugins/slack_ask_docs.bats`

Old:
```bash
  run grep -F -- "Usage: /ask-docs <question>" "${WORKER}"
```
New:
```bash
  run grep -F -- "Usage: /ask-docs [--sources] <question>" "${WORKER}"
```

### S2: `scripts/tests/plugins/vcluster_reconcile_namespace.bats:47`

Old:
```bash
  ! grep -q 'keep-me' "$VCLUSTER_CALLS"
```
New:
```bash
  run grep -q 'keep-me' "$VCLUSTER_CALLS"
  [ "$status" -ne 0 ]
```

### S3: `scripts/tests/plugins/ldap_password_rotator.bats`

Line 55. Old:
```bash
  ! sed -n "${preflight_line}p" "$ROTATE" | grep -Fq 'VAULT_TOKEN'
```
New:
```bash
  run grep -Fq 'VAULT_TOKEN' <<<"$(sed -n "${preflight_line}p" "$ROTATE")"
  [ "$status" -ne 0 ]
```

Line 77. Old:
```bash
  ! grep -Fq 'vault.vault.svc' "${REPO_ROOT}/plugins/ldap.sh"
```
New:
```bash
  run grep -Fq 'vault.vault.svc' "${REPO_ROOT}/plugins/ldap.sh"
  [ "$status" -ne 0 ]
```

### S4: `scripts/tests/plugins/keycloak.bats` (lines 207, 208, 236, 243, 244, 267)

Convert each `! grep -q '<pattern>' "$SMOKE_KUBECTL_LOG" || false` into two lines at the same indent, and drop the `|| false`:
```bash
  run grep -q '<pattern>' "$SMOKE_KUBECTL_LOG"
  [ "$status" -ne 0 ]
```
Keep every pattern exactly as it is. No later line in these tests reads `$output` or `$status` from an
earlier `run`. Line 236's test reruns `run` before the negation, which is still fine. If you find a later
read, stop and report it.
