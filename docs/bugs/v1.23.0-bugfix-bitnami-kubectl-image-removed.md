# Bugfix: v1.23.0 — bitnami/kubectl image removed from Docker Hub

**Branch:** `k3d-manager-v1.23.0`
**Files:** `scripts/etc/ldap/vars.sh`

---

## Problem

Bitnami removed the `docker.io/bitnami/kubectl` repository from Docker Hub (their August 2025
catalog migration to Bitnami Secure Images / the frozen `bitnamilegacy/` namespace). Every
manifest that pulls `docker.io/bitnami/kubectl:*` now fails with `ImagePullBackOff`
(`... not found`). On `k3d-manager-v1.23.0` the only in-source consumer is the OpenLDAP
password rotator, whose CronJob image defaults to `docker.io/bitnami/kubectl:latest`. The next
monthly rotation run (`0 0 1 * *`) will `ImagePullBackOff` and the rotation will silently not
happen. The `:latest` tag is also a CLAUDE.md security-rule violation (no floating tags).

**Root cause:** `scripts/etc/ldap/vars.sh:99` pins a container image
(`docker.io/bitnami/kubectl:latest`) that no longer exists on Docker Hub.

**Replacement image:** `docker.io/alpine/k8s:1.31.4` — already used (pinned) by
`scripts/etc/argocd/platform-ops/grafana-credential-rotator.yaml`, so this keeps the repo on one
maintained image family. The rotator invokes the image with an explicit
`command: ["sh"], args: ["/scripts/rotate.sh"]` and drives LDAP through `kubectl exec` (the old
image had no LDAP client tooling either), so `alpine/k8s` — which provides `sh` + `kubectl` on
PATH and runs fine as non-root — is a true drop-in with no entrypoint or capability change.

---

## Reproduction

```
# On the live hub cluster (context k3d-k3d-cluster):
kubectl get pods -A | grep ImagePullBackOff
# → any Job pod using docker.io/bitnami/kubectl:* is stuck:
#   Back-off pulling image "docker.io/bitnami/kubectl:...": ... not found
```

Expected: the rotator Job image pulls and the pod runs.
Actual: `ErrImagePull` / `ImagePullBackOff` — `docker.io/bitnami/kubectl` no longer resolves.

---

## Fix

### Change 1 — `scripts/etc/ldap/vars.sh`: re-pin the rotator image default

**Exact old block (line 99):**

```bash
export LDAP_ROTATOR_IMAGE="${LDAP_ROTATOR_IMAGE:-docker.io/bitnami/kubectl:latest}"
```

**Exact new block:**

```bash
export LDAP_ROTATOR_IMAGE="${LDAP_ROTATOR_IMAGE:-docker.io/alpine/k8s:1.31.4}"
```
