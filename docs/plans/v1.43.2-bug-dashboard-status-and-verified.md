## Goal

Today every bug doc is classed as either `open` or `closed` (`hermes.prior_art.doc_meta`). This
causes two problems:

- `IMPLEMENTED` and `DEFERRED` both count as open, so v1.43.2 shows 18 open while four of those
  fixes have landed.
- The table can show only open bugs.

Classify docs by **status** and **verified**, and use those in the table and in a summary strip
that follows the Release dropdown.

### Status

| Status | Doc `**Status:**` value begins with |
|---|---|
| `deferred` | `DEFERRED` |
| `fixed` | `IMPLEMENTED`, or anything `doc_meta` already treats as closed (FIXED, CLOSED, RESOLVED, DONE, WONTFIX, SUPERSEDED, DUPLICATE, VERIFIED, LIVE-VERIFIED, "Fixed in/on") |
| `unknown` | there is no status line (`doc_meta` returns `unknown`) |
| `open` | anything else |

### Verified

Verified means the fix was proven on a live cluster. The signal is the IMPLEMENTED → VERIFIED
move the docs already use.

| Verified | When |
|---|---|
| `true` | `fixed`, release v1.43.2 or later, status begins with `VERIFIED` or `LIVE-VERIFIED` |
| `false` | `fixed`, release v1.43.2 or later, any other fixed status |
| `n/a` | `fixed`, release before v1.43.2 or `unassigned`. The VERIFIED step was not a convention then, so `false` would be noise on about 600 historic docs. |
| (no label) | not `fixed` |

## Fix

### 1. `scripts/lib/hermes/prior_art.py`

Move the status-value extraction in `doc_meta` into a helper. `doc_meta` must return exactly what
it returns today for every input.

```python
def _status_value(text):
    match = _BOLD_STATUS_RE.search(text) or _BARE_STATUS_RE.search(text)
    value = match.group(1).strip() if match else None
    if value is None:
        heading = _STATUS_HEADING_RE.search(text)
        if heading:
            value = next((line.strip() for line in text[heading.end():].splitlines() if line.strip()), None)
    return value
```

Rewrite `doc_meta` to use `_status_value`. Then add:

```python
_DEFERRED_RE = re.compile(r"^DEFERRED\b", re.IGNORECASE)
_IMPLEMENTED_RE = re.compile(r"^IMPLEMENTED\b", re.IGNORECASE)
_VERIFIED_RE = re.compile(r"^(?:VERIFIED|LIVE-VERIFIED)\b", re.IGNORECASE)


def doc_status(text):
    """Return ``(priority, status, live_verified)``: status is open, fixed, deferred or unknown."""
    priority, state = doc_meta(text)
    value = _status_value(text)
    if state == "unknown":
        return priority, "unknown", False
    if _DEFERRED_RE.search(value):
        return priority, "deferred", False
    if state == "closed" or _IMPLEMENTED_RE.search(value):
        return priority, "fixed", bool(_VERIFIED_RE.search(value))
    return priority, "open", False
```

`doc_meta`, `doc_release` and every existing caller are unchanged.
