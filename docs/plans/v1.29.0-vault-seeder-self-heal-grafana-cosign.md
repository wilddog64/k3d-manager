# v1.29.0 — Self-healing Vault bring-up seeders (Grafana + cosign)

**Branch:** `k3d-manager-v1.29.0`
**Owner:** Codex (implementation) → Claude (live verification, deferred)
**Origin:** Follow-up from `docs/issues/2026-09-05-vault-kv-and-eso-policy-loss-grafana-cosign.md`.

## Problem

A full k3d cluster rebuild wipes Vault's raft store (`local-path` PVC). On rebuild,
ldap/keycloak KV paths are re-seeded automatically, but two are not, so they need
manual remediation every time:

1. **`secret/observability/grafana`** — the writer *policy* + *role* are re-created on
   bring-up (`_observability_apply_grafana_rotator`), but the **KV data is never
   written**. Result: Grafana pod stuck in `CreateContainerConfigError` until seeded
   by hand. There is **no backup** of this password anywhere — the rotator reads the
   *old* value from Vault itself — so recovery is "generate a fresh admin password",
   not "restore".
2. **`secret/cosign/signing`** + the `cosign-verify` policy + its grant on the
   `eso-ldap-directory` role — seeded **only** by the manual `signing_init` /
   `deploy_image_signing`, both of which **regenerate** the keypair and clobber the
   Keychain backup. There **is** a real Keychain backup (`k3d-manager-signing`), and
   the key is precious — so recovery must be a **restore that never regenerates**.

## Goal

- **Grafana:** on bring-up, if `secret/observability/grafana` is absent, seed a
  freshly generated admin password (username `admin`) matching the rotator schema.
  Idempotent: present → skip.
- **cosign:** add a non-destructive restore path that seeds `secret/cosign/signing`
  from the `k3d-manager-signing` Keychain backup (deriving `cosign.pub` on the host,
  never regenerating), then re-applies the `cosign-verify` policy + ESO role grant.
  Make standard `signing_init` **prefer this restore** when the Vault path is absent
  but a Keychain backup exists — so bring-up self-heals without clobbering the key.

**Not in scope for Codex:** running any seeder against the live hub. Live verification
is Claude's follow-up step, gated separately. Codex writes code + BATS only.

## Change 1 — `scripts/plugins/signing.sh`

### 1a. Add `_signing_keychain_backup_exists` (insert immediately AFTER `_signing_seed_vault_key`, which ends at line ~151)

```bash
function _signing_keychain_backup_exists() {
  _no_trace _secret_load_data "${SIGNING_KEYCHAIN_SERVICE}" \
    "${SIGNING_KEYCHAIN_KEY_ACCOUNT}" >/dev/null 2>&1 \
    && _no_trace _secret_load_data "${SIGNING_KEYCHAIN_SERVICE}" \
      "${SIGNING_KEYCHAIN_PASSWORD_ACCOUNT}" >/dev/null 2>&1
}

function _signing_restore_vault_from_keychain() {
  local vault_ns="${1:-${VAULT_NS:-${VAULT_NS_DEFAULT:-vault}}}"
  local vault_release="${2:-${VAULT_RELEASE:-${VAULT_RELEASE_DEFAULT:-vault}}}"
  local key password
  key=$(_no_trace _secret_load_data "${SIGNING_KEYCHAIN_SERVICE}" \
    "${SIGNING_KEYCHAIN_KEY_ACCOUNT}") || return 1
  password=$(_no_trace _secret_load_data "${SIGNING_KEYCHAIN_SERVICE}" \
    "${SIGNING_KEYCHAIN_PASSWORD_ACCOUNT}") || return 1
  [[ -n "${key}" && -n "${password}" ]] || return 1

  # `security -w` hex-encodes multi-line values (the PEM key); decode when the
  # value did not come back as a PEM block.
  case "${key}" in
    *BEGIN*) : ;;
    *) key=$(printf '%s' "${key}" | xxd -r -p) ;;
  esac

  (
    local workdir
    workdir="$(mktemp -d "${TMPDIR:-/tmp}/k3dm-signing.XXXXXX")"
    trap 'rm -rf -- "${workdir}"' EXIT
    printf '%s\n' "${key}" > "${workdir}/cosign.key"
    if ! COSIGN_PASSWORD="${password}" _no_trace _run_command -- \
        cosign public-key --key "${workdir}/cosign.key" > "${workdir}/cosign.pub" 2>/dev/null; then
      _err "[signing] could not derive public key from Keychain backup; aborting restore"
      return 1
    fi
    [[ -s "${workdir}/cosign.pub" ]] || {
      _err "[signing] empty public key derived from backup; aborting restore"
      return 1
    }
    _signing_write_vault "${vault_ns}" "${vault_release}" \
      "${workdir}/cosign.key" "${password}" "${workdir}/cosign.pub"
  )
}
```

### 1c. Add the public `signing_restore` recovery command (insert AFTER `signing_rotate_key`, before `signing_status`, ~line 338)

```bash
function signing_restore() {
  local vault_ns="${1:-${VAULT_NS:-${VAULT_NS_DEFAULT:-vault}}}"
  local vault_release="${2:-${VAULT_RELEASE:-${VAULT_RELEASE_DEFAULT:-vault}}}"
  if _signing_vault_key_exists "${vault_ns}" "${vault_release}"; then
    _info "[signing] Vault key already present at ${SIGNING_VAULT_PATH}; not restoring key material"
  elif _signing_keychain_backup_exists; then
    _signing_restore_vault_from_keychain "${vault_ns}" "${vault_release}" || return 1
    _info "[signing] restored cosign signing material from Keychain backup"
  else
    _err "[signing] no Vault key and no Keychain backup — nothing to restore; run signing_init to generate"
    return 1
  fi
  _signing_apply_vault_policy "${vault_ns}" "${vault_release}"
  _signing_grant_eso_read "${vault_ns}" "${vault_release}"
  _signing_apply_pub_externalsecret
}
```

`signing_restore` is public (no underscore) so the dispatcher auto-exposes it as
`./scripts/k3d-manager signing_restore`. No registration change needed.

## Change 2 — `scripts/plugins/observability.sh`

### 2a. Add `_observability_seed_grafana_if_absent` (insert immediately BEFORE `_observability_apply_grafana_rotator`, ~line 103)

```bash
function _observability_seed_grafana_if_absent() {
  local vault_ns="${1:-secrets}" vault_release="${2:-vault}"
  local mount="secret" path="observability/grafana"
  local check_cmd
  printf -v check_cmd 'vault kv get -mount=%q %q >/dev/null 2>&1' "${mount}" "${path}"
  if _vault_exec --no-exit "${vault_ns}" "${check_cmd}" "${vault_release}" >/dev/null 2>&1; then
    _info "[observability] Grafana admin credential already present in Vault; skipping seed"
    return 0
  fi
  local password
  password="$(head -c 24 /dev/urandom | od -An -tx1 | tr -d ' \n')"
  [[ -n "${password}" ]] || { _err "[observability] failed to generate Grafana admin password"; return 1; }
  local put_cmd
  printf -v put_cmd 'vault kv put -mount=%q %q username=%q password=%q >/dev/null && echo SEEDED' \
    "${mount}" "${path}" "admin" "${password}"
  if printf '%s\n' "${put_cmd}" \
      | _no_trace _vault_exec_stream --no-exit --stdin "${vault_ns}" "${vault_release}" -- sh -s >/dev/null; then
    _info "[observability] Seeded Grafana admin credential in Vault (fresh password)"
  else
    _err "[observability] failed to seed Grafana admin credential in Vault"
    return 1
  fi
}
```

The password generator (`head -c 24 /dev/urandom | od -An -tx1 | tr -d ' \n`) is the
**same one the rotator uses** (`grafana-credential-rotator.yaml` line ~112) — keep it
identical for consistency. The `printf %q` + stdin `_vault_exec_stream` pattern
mirrors `_signing_write_vault`: the password is never in argv and `_no_trace`
suppresses tracing.

### 2b. Call the seed as the FIRST statement of `_observability_apply_grafana_rotator`

Find:

```bash
function _observability_apply_grafana_rotator() {
  local manifest="${SCRIPT_DIR}/etc/argocd/platform-ops/grafana-credential-rotator.yaml"
```

Insert one line right after the `function ... {` line, before `local manifest=`:

## Change 3 — BATS (pure logic, function stubs only — no live cluster)

### 3a. `scripts/tests/plugins/signing.bats` — add cases

Stub the Vault/Keychain/apply helpers as bash functions in a local `setup`/per-test
so no cluster is touched. Add tests asserting:

- `signing_restore` is a declared function (`declare -f signing_restore`).
- **Vault key present:** stub `_signing_vault_key_exists` → returns 0. Call
  `signing_restore`; assert `_signing_restore_vault_from_keychain` was **not** called
  (use a stub that writes a sentinel file / sets a global) and that
  `_signing_apply_vault_policy`, `_signing_grant_eso_read`,
  `_signing_apply_pub_externalsecret` **were** called.
- **Key absent + backup present:** stub `_signing_vault_key_exists` → 1,
  `_signing_keychain_backup_exists` → 0 (true), `_signing_restore_vault_from_keychain`
  → sentinel. Assert restore called; `_signing_seed_vault_key` **not** called.
- **Key absent + no backup:** `_signing_vault_key_exists` → 1,
  `_signing_keychain_backup_exists` → 1 (false). Assert `signing_restore` returns
  non-zero and does **not** call policy/grant/ES.
- **`signing_init` prefers restore over regenerate:** key absent + backup present →
  `_signing_restore_vault_from_keychain` called, `_signing_seed_vault_key` **not**
  called.

### 3b. New file `scripts/tests/plugins/observability_grafana_seed.bats`

Stub `_vault_exec` and `_vault_exec_stream`. Add tests:

- **Present:** `_vault_exec` returns 0 → `_observability_seed_grafana_if_absent`

- **Absent:** `_vault_exec` returns 1 → the function calls `_vault_exec_stream`
