# v0.5.0 — `_agent_audit` learns Python

**Branch:** `feat/agent-audit-python`
**Requested by:** CK, 2026-09-30, via k3d-manager `docs/plans/v1.41.0-python-agent-rigor.md` (milestone M1,
"Codex brief A"). k3d-manager adopts it in a later subtree pull (brief B); this spec is lib-foundation only.

## Problem

`_agent_audit` checks shell, BATS and YAML only. A staged Python change gets no commit-time check. k3d-manager
now has ~74 Python files, 9 of them with no `.py` extension (`bin/k3dm-hermes`, `bin/k3dm-webhook`, …), and
~420 Python test functions with no guard against deleting or weakening them. The BATS suites have one.

**Already done, not in scope:** the plan's item 4 (one copy of the library). k3d-manager's
`scripts/lib/agent_rigor.sh` became a shim that sources this repo's copy on 2026-10-04 (`e22b7df6`), and
k3d-manager no longer has `scripts/lib/acg`, so `AGENT_AUDIT_BATS_EXCLUDE` is not needed.

## Definitions

- **Staged Python file:** a path in `git diff --cached --name-only --no-renames -z` that ends in `.py`, **or**
  whose first line matches `^#!.*python`. Read the first line from the staged blob (`git show :<path>`); for a
  file deleted in the index, read it from `HEAD:<path>`.
- **Python test file:** a staged Python file whose path **or** basename matches one of the space-separated
  globs in `AGENT_AUDIT_PY_TEST_GLOB` (default `*/tests/* test_*.py *_test.py`). Split the list with
  `read -r -a`, never an unquoted `for g in $var` (that would glob-expand against the working directory).

## Fix spec

### File 1 — `scripts/lib/agent_rigor.sh`

Add three private helpers above `_agent_audit` and three checks inside it, after the existing YAML IP check and
before `return "$status"`. Bash 3.2 only: no `declare -A`, no `mapfile`, no `${var,,}`. 3-space indentation,
like the rest of the file.

1. **Helpers.**
   - `_agent_audit_is_python <path> <rev>`: returns 0 for `*.py`, else 0 when
     `git show "<rev>:<path>" | head -n 1` matches `^#!.*python`. `<rev>` is empty for the index, `HEAD` for a
     deleted file.
   - `_agent_audit_is_py_test <path>`: returns 0 when the path or `${path##*/}` matches a glob as defined above.
   - `_agent_audit_py_files`: prints staged Python files, NUL-separated, with a one-character status prefix
     `D` (deleted from the index: `git cat-file -e ":<path>"` fails) or `A` (present). The checks below loop over
     it.

2. **Test-shrink guard** (a port of the BATS rule). Concatenate `git diff --cached --no-renames -- <file>` for
   every Python test file, deleted ones included (deleting a whole test file must count). Then:
   - removed `^-[[:space:]]*(async[[:space:]]+)?def[[:space:]]+test_` lines > added `^\+…` lines →
     `_warn "Agent audit: number of test functions decreased in Python test files"`, `status=1`;
   - any removed line matching `^-[[:space:]]*(assert([[:space:](]|$)|self\.assert)` →
     `_warn "Agent audit: assertions removed from Python test files"`, `status=1`.

   Like the BATS rule, an edited assertion counts as removed. That is intentional; the operator overrides with
   `--no-verify` knowingly, never an agent.

3. **Syntax.** For each present (not deleted) staged Python file, compile the **staged blob**, never the
   working-tree file:
   ```bash
   git show :"$file" | "$py" -c 'import sys; compile(sys.stdin.buffer.read(), sys.argv[1], "exec")' "$file"
   ```
   `py="${AGENT_AUDIT_PYTHON:-python3}"`. On failure: `_warn "Agent audit: Python syntax error in $file:"`, then
   `_warn` the last line of the captured stderr, `status=1`. If `command -v "$py"` fails, print one
   `_warn "Agent audit: $py not found; skipping Python syntax check"` and skip only this check.

4. **Dangerous calls.** For each present staged Python file that is **not** a test file, take the added lines:
   `git diff --cached -- "$file" | grep '^+' | grep -v '^+++' | sed 's/^+//'`, drop lines whose first non-space
   character is `#`, then check each rule with two parallel indexed arrays (rule name, ERE):

   | rule | ERE |
   |---|---|
   | `shell-true` | `shell[[:space:]]*=[[:space:]]*True` |
   | `eval` | `(^|[^[:alnum:]_.])eval[[:space:]]*\(` |
   | `exec` | `(^|[^[:alnum:]_.])exec[[:space:]]*\(` |
   | `sudo` | `["']sudo["']` |
   | `sensitive-flag` | `["']--(password|token|username)(=[^"']*)?["']` |

   The `[^[:alnum:]_.]` guard keeps `model.eval()`, `os.execv(` and `create_subprocess_exec(` out. A line is
   exempt from a rule only when it carries `# agent-audit: allow <rule> <reason>`, with a non-empty reason:
   ERE `#[[:space:]]*agent-audit:[[:space:]]*allow[[:space:]]+<rule>[[:space:]]+[^[:space:]]`. On a hit:
   `_warn "Agent audit: <rule> in $file (add '# agent-audit: allow <rule> <reason>' if intended):"`, `_warn` the
   lines, `status=1`.

### File 1, continued — `_agent_lint` file globs

Replace the hardcoded `-- '*.sh' '*.js' '*.md'` with `AGENT_LINT_GLOBS` (default `*.sh *.js *.md`), split with
`read -r -a` and passed quoted as git pathspecs. This lets a consumer add Python to AI lint by config.

### File 2 — `scripts/tests/lib/agent_rigor.bats`

Use the existing `setup` (a temporary git repository). Every new test stages content with `git add` and runs
`run _agent_audit`. Add:

1. `def test_` removed from `tests/test_a.py` → fail, output names "test functions decreased".
2. `assert` line removed → fail; a `self.assertEqual` line removed → fail.
3. A test function added (no removals) → pass.
4. `git rm` of a committed `tests/test_a.py` → fail.
5. An extensionless `bin/tool` starting `#!/usr/bin/env python3` with a syntax error → fail, output names
   `bin/tool`.
6. The same broken content as `notes.txt`, no shebang → pass.
7. **Staged blob, not working tree:** stage a broken `x.py`, then fix the working-tree copy without staging →
   fail. And the reverse (valid staged, broken working tree) → pass.
8. `AGENT_AUDIT_PYTHON=/nonexistent/python3` with a broken `x.py` → exit 0, output says "not found".
9. Each of the 5 rules in `app.py` → fail, output names the rule.
10. The same lines with `# agent-audit: allow <rule> stubbed in tests` → pass.
11. The marker **without** a reason → fail.
12. A `shell=True` line in `tests/test_a.py` → pass (test files are exempt).
13. `model.eval()`, `os.execv(path, args)` and `create_subprocess_exec(` → pass.
14. A commented-out `# subprocess.run(x, shell=True)` → pass.
15. `AGENT_AUDIT_PY_TEST_GLOB='checks/*'` makes `checks/x.py` a test file (shrink guard applies); a file named
    `test_*.py` in the working directory must not break glob splitting.
16. `_agent_lint` with `AGENT_LINT_GLOBS='*.py'`, `ENABLE_AGENT_LINT=1` and a stub AI function that prints its
    prompt: a staged `a.py` appears in the prompt and a staged `a.sh` does not. (Create
    `$SCRIPT_DIR/etc/agent/lint-rules.md` in the test repo.)

Existing tests must stay green and unedited.

## Rules

- Modify only Files 1–3. Do not touch `scripts/lib/acg/`, `system.sh`, `core.sh` or the hook.
- Do not commit or push: leave changes unstaged (`.git` writes are denied in your sandbox). Claude commits.
- Never use the network, the Keychain, or real credentials in tests.
- Run and paste:
  - `env -i HOME="$HOME" PATH="/usr/local/bin:/usr/bin:/bin:/opt/homebrew/bin" TMPDIR="$TMPDIR" bash --norc --noprofile -c 'bats scripts/tests/lib/'`
  - `shellcheck scripts/lib/agent_rigor.sh`
  - `/bin/bash --version | head -1` and the BATS file run under `/bin/bash` 3.2 if `bats` allows it.
- Mutations: snapshot `scripts/lib/agent_rigor.sh` first (`cp` to `$TMPDIR`), apply one at a time, run BATS,
  paste the red test names, restore, and prove the restore with `cmp`:
  1. drop shebang detection → test 5 red;
  2. compile the working-tree file instead of the staged blob → test 7 red;
  3. drop the reason requirement from the marker ERE → test 11 red;
  4. drop the `[^[:alnum:]_.]` guard → test 13 red.

## Done when

- A staged change that deletes a Python test, adds `shell=True` outside tests, or breaks the syntax of an
  extensionless Python script makes `_agent_audit` return non-zero with a message naming the file and rule.
- All BATS green; shellcheck clean; 4 mutations shown red and restored.
