# Spec: v1.21.0 — k3dm-webhook security hardening

**Branch:** `k3d-manager-v1.21.0`
**Files:** `bin/k3dm-webhook`, `scripts/lib/webhook/auth.py`, `scripts/lib/webhook/config.py`, `bin/k3dm-ask-bash`, `scripts/tests/lib/webhook.bats`

---

## Problem

Security review of the webhook (2026-08-01) found the **bearer token is the only real
privilege boundary**, and it maps to full admin. The RBAC tiers, the prompt-injection
filter, and the `ask` sandbox are all defense-in-depth that can be bypassed. Threat model
for this release: **internet-facing** (the surface is reachable through the Cloudflare
Worker → cloudflared tunnel), so auth edges + rate limiting are prioritized.

**Root causes (by finding):**
- **#1** `_ACTION_POLICY` role gate is enforced only in the `/api/*` branch of `do_POST`; the
  `/slack/events` branch dispatches `_handle_thread_command` (cluster-up/down/resume/refresh/ask)
  with **no role check** — channel membership = operator/admin capability.
- **#2** Roles are client-asserted via `X-K3DM-Role`, and `_ROLE_DEFAULT = "admin"` makes a
  missing/garbled header **fail open to admin**.
- **#3** `k3dm-ask-bash` is a grep denylist over a reconstructed string, then `exec /bin/bash "$@"` —
  bypassable via interpreters (`python3 -c`, `perl`, `node`), `$(...)`/backticks, and `>`/`>>`
  redirection (redirect targets are never scope-checked).
- **#5** `GEMINI_CLI_TRUST_WORKSPACE=true` disables agy's own guardrails on the ask path.
- **#6** No rate limiting on either entry surface.
- **#7** POST-body `json.loads` is unguarded → malformed JSON kills the handler thread (cheap DoS).
- **#8** `TOKEN_FILE` plaintext fallback read with no permission check.
- **#9** `_seen_event_ids` grows unbounded and resets on restart.

---

## Design decisions (locked with owner 2026-08-01)

- **Slack authorization = per-user allowlist.** Extract `ev["user"]` from the Slack event, map
  known Slack user IDs → `reader|operator|admin` via `K3DM_SLACK_ROLE_MAP` (env or Keychain),
  enforce the SAME action policy on thread commands. **Unknown Slack user → `reader`.**
- **Fail-closed roles.** Header ABSENT (direct token) → `admin` (token possession IS the admin
  credential — unchanged). Header PRESENT but unrecognized → `reader` (was: admin).
- **Threat model = internet-facing.** Add rate limiting; treat both surfaces as adversarial.
- **`ask` sandbox stays a denylist for now but blocks the known bypass classes**
  (interpreters + redirection + command-prefix maskers). A true OS sandbox
  (`sandbox-exec` seatbelt profile / container) is the durable follow-up — **out of scope here**,
  filed as a note in Definition of Done.

```python
def _load_slack_role_map():
    """Parse 'U012:admin,U045:operator' from env or Keychain into {user_id: role}."""
    raw = os.environ.get("K3DM_SLACK_ROLE_MAP") or _keychain_secret("k3dm-slack-role-map")
    mapping = {}
    for pair in (raw or "").split(","):
        pair = pair.strip()
        if not pair or ":" not in pair:
            continue
        uid, _, role = pair.partition(":")
        uid = uid.strip()
        role = role.strip().lower()
        if uid and role in ("reader", "operator", "admin"):
            mapping[uid] = role
    return mapping


SLACK_ROLE_MAP = _load_slack_role_map()


def _slack_user_role(user_id):
    """Resolve a Slack user ID to reader|operator|admin. Unknown → reader (fail closed)."""
    return SLACK_ROLE_MAP.get((user_id or "").strip(), "reader")
```

```python
def _rate_limited(bucket):
    """Fixed-window per-bucket limiter. Returns True if the caller is over budget."""
    now = time.time()
    with _rate_lock:
        window_start, count = _rate_hits.get(bucket, (now, 0))
```

**Exact new block:**

```bash
# ── Always blocked (both modes) ───────────────────────────────────────────────

# Destructive filesystem / process commands
if echo "$CMD" | grep -qE '\b(rm|rmdir|dd|mkfs|shred|truncate|mv|chmod|chown|kill|killall|pkill)\b'; then
  _deny "$CMD"
fi

# General-purpose interpreters — bypass every denylist above, so block outright.
if echo "$CMD" | grep -qE '\b(python[0-9.]*|perl|ruby|node|deno|bun|osascript|php|lua|tclsh|Rscript|gdb|lldb)\b'; then
  _deny "$CMD"
fi

# Nested shell invocation and command-prefix maskers that hide the real command.
if echo "$CMD" | grep -qE '\b(bash|sh|zsh|ksh|dash)\b\s+-c\b|\b(env|xargs|nice|nohup|timeout|sudo|command|builtin|exec|eval|watch|setsid)\b'; then
  _deny "$CMD"
fi

# Output redirection / process substitution — can write or overwrite arbitrary paths
# that the per-arg scope loop never sees (the target lives inside the -c string).
if echo "$CMD" | grep -qE '(>>?|<\()'; then
  _deny "$CMD"
fi
```

> **Known limitation (documented, not fixed here):** this remains a denylist. `$(...)` and
> backtick command substitution can still smuggle a blocked token past the literal grep (e.g.
