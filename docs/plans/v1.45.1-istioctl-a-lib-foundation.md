## Problem

`_install_istioctl` (`lib-foundation/scripts/lib/core.sh:455-491`) accepts any istioctl on PATH ("already exists, skip
installation"), and when none is present it runs `downloadIstioCandidate.sh` from `istio/istio` master with no checksum
and replaces the caller's EXIT trap. On m2-air Homebrew istioctl 1.32.0 then rejected the pinned k3s v1.32 image at
`x precheck` (IST0142), so `make dr-drill` and a fresh `hub-up` fail. Full analysis, captures and rollout survey: parent.

## Behaviour

From the parent, Behaviour 1–7:

1. Pin: `${ISTIOCTL_VERSION:-1.31.4}`.
2. New `_istioctl_pinned_sha256 <version> <os> <arch>` prints the pinned SHA-256 (table below) and returns non-zero for any
   other version or os/arch.
3. Existing binary: check `${install_dir}/istioctl` first, then `command -v istioctl`. Parse stdout with the anchored
   `^client version: ([0-9]+)\.([0-9]+)\.`. Same minor as the pin → accept, rc 0, print
   `istioctl <found> at <path> matches pin <pin> (minor <X.Y>)`, no download.
4. Another minor, or output that does not match (including the line only on stderr) → `_err` with one line naming the found
   version (or `unknown`), its path, the pin and the fix (release URL, `brew unlink istioctl`, `ISTIOCTL_VERSION`). `_err`,
   not `return 1`: the callers (`k3d.sh:59,61,104`, `k3s.sh:88` in k3d-manager) call it bare without `set -e`.
5. Download `${ISTIOCTL_BASE_URL:-https://github.com/istio/istio/releases/download}/<v>/istioctl-<v>-<os>-<arch>.tar.gz`
   with `curl -fsSL` into `mktemp -d`; verify with `shasum -a 256` or `sha256sum`; on mismatch remove the temp dir and
   `_err`. Extract (single root entry `istioctl`) and install into `install_dir` (default `/usr/local/bin`) through
   `_run_command --prefer-sudo` fallbacks as today.
6. After install, run the installed binary by full path (`"${install_dir}/istioctl"`, same version command as check 3)
   and apply check 3.
7. No master fetch, no global EXIT trap (clean up the temp dir explicitly), no `cd`/`pushd`, Bash 3.2, every expansion
   quoted.
