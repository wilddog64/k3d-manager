## Contract 1 — the e2e result event ConfigMap (written by the harness)

The harness (`e2e.sh`, `_e2e_write_result_event`, defined in the harness spec) writes ONE ConfigMap per
run into `platform-ops`. This is the authoritative shape:

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  generateName: e2e-result-
  namespace: platform-ops
  labels:
    k3dm.k3d.io/e2e-result: "true"          # exporter selector
    k3dm.k3d.io/e2e-service: "<service>"    # for GC grouping
    k3dm.k3d.io/e2e-tier: "<tier>"          # for GC grouping
data:
  created_at: "<RFC3339>"                   # ordering/cap key (mirror CVE events)
  event.json: |
    {"run_id":"<uuid>","tier":"vcluster|sandbox","service":"<order|basket|…|all>",
     "project":"api|flow|stripe","candidate_digest":"sha256:…","passed":"true|false",
     "total":"<N>","failed":"<N>","duration_seconds":"<N>","timestamp":"<RFC3339>","commit":"<gitsha>"}
```

- `timestamp` is **RFC3339** (the exporter parses it with the existing `timestamp()` ISO helper —
  a unix number would parse to 0). `duration_seconds` is numeric.
- Match dashboards/rules on `run_id` / `candidate_digest` **as emitted** — do NOT re-derive from
  `image_repository` (the `ghcr.io/` normalization + multi-arch OCI-index-digest traps burned the CVE
  work: `reference_trivy_vs_remediation_image_repository_label_mismatch`,
  `reference_containerd_index_digest_aliasing_verifier`).

**Add a reader mirroring `refresh_remediation_events()` (after that function, ~line 152):**

```python
    def refresh_e2e_events():
        global e2e_state
        req = Request(BASE + "/api/v1/namespaces/platform-ops/configmaps?labelSelector=k3dm.k3d.io%2Fe2e-result%3Dtrue")
        req.add_header("Authorization", "Bearer " + TOKEN)
        try:
            with urlopen(req, context=ssl.create_default_context(cafile=CA), timeout=15) as response:
                items = json.load(response).get("items", [])
            events = []
            items.sort(key=lambda item: timestamp(item.get("data", {}).get("created_at", "")))
            for item in items[-200:]:
                data = item.get("data", {})
                payload = event_payload(data.get("event.json"))
                events.append({
                    "run_id": payload.get("run_id") or item.get("metadata", {}).get("name", ""),
                    "tier": payload.get("tier", ""),
                    "service": payload.get("service", ""),
                    "project": payload.get("project", ""),
                    "candidate_digest": payload.get("candidate_digest", ""),
                    "commit": payload.get("commit", ""),
                    "passed": str(payload.get("passed", "")).lower() == "true",
                    "total": payload.get("total", ""),
                    "failed": payload.get("failed", ""),
                    "duration_seconds": payload.get("duration_seconds", 0),
                    "run_seconds": timestamp(payload.get("timestamp") or data.get("created_at", "")),
                })
            e2e_state = events
        except Exception:
            e2e_state = []
```

**After the CVE emit loop (after line 216, before `payload = …`):** compute per-`(tier,service,project)`
latest + last-success in the exporter (snapshot model → gauges, not counters), and a per-run info series:

```python
            lines.extend([
                "# HELP e2e_run_info Retained e2e run details for dashboards",
                "# TYPE e2e_run_info gauge",
                "# HELP e2e_last_run_pass Most recent e2e run passed (1) or failed (0)",
                "# TYPE e2e_last_run_pass gauge",
                "# HELP e2e_last_run_timestamp_seconds Unix timestamp of the most recent e2e run",
                "# TYPE e2e_last_run_timestamp_seconds gauge",
                "# HELP e2e_last_run_duration_seconds Duration of the most recent e2e run",
                "# TYPE e2e_last_run_duration_seconds gauge",
                "# HELP e2e_last_success_timestamp_seconds Unix timestamp of the most recent passing e2e run",
                "# TYPE e2e_last_success_timestamp_seconds gauge",
            ])
            latest = {}
            latest_success = {}
            for event in e2e_state:
                dims = (event["tier"], event["service"], event["project"])
                if dims not in latest or event["run_seconds"] > latest[dims]["run_seconds"]:
                    latest[dims] = event
                if event["passed"] and (dims not in latest_success or event["run_seconds"] > latest_success[dims]):
                    latest_success[dims] = event["run_seconds"]
                info = {key: event[key] for key in ("run_id", "tier", "service", "project", "candidate_digest", "commit", "total", "failed")}
                info["passed"] = str(event["passed"]).lower()
                info_body = ",".join('%s="%s"' % (key, esc(value)) for key, value in info.items())
                lines.append("e2e_run_info{" + info_body + "} 1")
            for dims, event in latest.items():
                body = 'tier="%s",service="%s",project="%s"' % (esc(dims[0]), esc(dims[1]), esc(dims[2]))
                lines.append("e2e_last_run_pass{" + body + "} " + ("1" if event["passed"] else "0"))
                lines.append("e2e_last_run_timestamp_seconds{" + body + "} " + str(event["run_seconds"]))
                lines.append("e2e_last_run_duration_seconds{" + body + "} " + str(event["duration_seconds"]))
                if dims in latest_success:
                    lines.append("e2e_last_success_timestamp_seconds{" + body + "} " + str(latest_success[dims]))
```

**Metric surface (authoritative):**

| Metric | Type | Labels | Use |
|---|---|---|---|
| `e2e_run_info` | gauge=1 | run_id, tier, service, project, candidate_digest, commit, total, failed, passed | recent-runs table |
| `e2e_last_run_pass` | gauge 1/0 | tier, service, project | red/green status |
| `e2e_last_run_timestamp_seconds` | gauge | tier, service, project | freshness |
| `e2e_last_run_duration_seconds` | gauge | tier, service, project | duration trend |
| `e2e_last_success_timestamp_seconds` | gauge | tier, service, project | staleness alert |

## Change 3 — dashboard `grafana-dashboard-e2e.yaml` (new CM)

A Grafana dashboard ConfigMap (label `grafana_dashboard: "1"` per the existing provisioning), an **E2E
row** with these panels (PromQL exact; panel JSON transcribed to match the existing dashboards' shape):

1. **Status by service/tier** — stat/table, `e2e_last_run_pass` → value map `1→PASS(green)`, `0→FAIL(red)`.
2. **Last success age** — stat, `time() - e2e_last_success_timestamp_seconds`, unit `s`, red threshold
   (e.g. > 3d). Missing series = never passed → also red.
3. **Duration trend** — timeseries, `e2e_last_run_duration_seconds{service=~"$service"}`, unit `s`.
4. **Recent runs** — table from `e2e_run_info`, columns run_id / tier / service / project / passed /
   candidate_digest / commit (instant query, last value).
5. **Failures in window** — stat, `count by (service,tier) (e2e_run_info{passed="false"})`.

Template variables: `$service`, `$tier` from `label_values(e2e_run_info, service)` / `(…, tier)`.

## Change 4 — alert rule (platform-ops)

Add to the platform-ops PrometheusRule (the same rule file/CM the CVE alerts use), routed via the
existing Alertmanager — **owned alerts, NOT the `k3dm-quiet` blackhole**:

```yaml
- alert: E2EVerificationFailing
  expr: e2e_last_run_pass == 0
  for: 10m
  labels: { severity: warning, tier: e2e }
  annotations:
    summary: "e2e {{ $labels.project }} failing on {{ $labels.tier }} for {{ $labels.service }}"
- alert: E2EVerificationStale
  expr: time() - e2e_last_success_timestamp_seconds > 259200   # 3d; tune per cadence
  for: 30m
  labels: { severity: warning, tier: e2e }
  annotations:
    summary: "no passing e2e for {{ $labels.service }}/{{ $labels.tier }} in >3d"
```

## Change 6 — event GC / TTL (bounded writer + reuse CVE GC)

e2e-result ConfigMaps accumulate in etcd. Two-layer bound:
- **Exporter read is already capped** at `items[-200:]` (Change 1) — dashboards never blow up.
- **Writer prunes on write:** after writing a new event, `_e2e_write_result_event` deletes all but the
  most recent **N=20** ConfigMaps per `(k3dm.k3d.io/e2e-service, k3dm.k3d.io/e2e-tier)` label pair.
  When the CVE-event GC (task #19) lands, extend it to also sweep `k3dm.k3d.io/e2e-result=true` and drop
  the writer-side prune. (The writer-side bound is self-contained; it does not block on task #19.)
