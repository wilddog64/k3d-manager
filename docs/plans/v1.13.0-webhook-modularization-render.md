## Goal

Second in-repo modularization slice. Move the three Slack **output** helpers out of
`bin/k3dm-webhook` into a new `scripts/lib/webhook/render.py`, keeping the entrypoint thin.
This is a **pure move** — no logic, value, or command-behavior changes.

The three functions are the natural `render.py` module (per the design doc). All of their
cross-module dependencies (`SLACK_BOT_TOKEN`, `SLACK_CHANNEL_ID`) already live in
`scripts/lib/webhook/config.py` from the config slice, and the `sys.path` shim + package
already exist. So this slice touches only **2 files** and needs **no bats changes** (there are
no source-grep assertions on these three functions).

### Why these three (and not `auth` next)

`auth.py` (`_get_token`, `_verify_slack_signature`) is deferred: it depends on the shared
`_spawn_capture_text` subprocess helper (8 callers across the file) and on
`SLACK_SIGNING_SECRET`, which is a **function-derived** constant (it shells out to
`security find-generic-password` at import time via `_keychain_secret`). Extracting auth
cleanly requires first deciding where `_spawn_capture_text` lives and whether the
signing-secret lookup should stay lazy. That is its own handoff. The render helpers have
none of those entanglements.

---

## Scope

**In scope — move verbatim into `render.py`:**

- `_slack_post(url, text)` — POST text to a Slack incoming webhook / response_url
- `_post_slack_bot(text, thread_ts=None)` — POST to Slack `chat.postMessage`
- `_fetch_thread_context(thread_ts, limit=20)` — fetch + clean a Slack thread

**Explicitly OUT of scope (leave in `bin/k3dm-webhook`):**

- `_verify_slack_signature` and `_get_token` — auth, a later slice (blocked on `_spawn_capture_text` / `SLACK_SIGNING_SECRET`)
- `_spawn_capture_text`, `_keychain_secret` — shared subprocess/secret helpers
- Any command/dispatch/diagnostics helpers (`_run_cluster_*`, `_handle_thread_command`, …)
- Mutable global state (`_seen_event_ids`, `_running_procs`, `_running_procs_lock`, `_ask_semaphore`, `_k3d_ssl_ctx`, `_k3d_server`)
- Function-derived constants (`SLACK_SIGNING_SECRET`, `GEMINI_MODEL`) and the role/policy/diagnostic tables

## Change 1 — new file `scripts/lib/webhook/render.py`

Create with **exactly** this content:

```python
#!/usr/bin/env python3
"""Slack response/rendering helpers for k3dm-webhook.

Phase 1 of the in-repo modularization (see
docs/plans/v1.13.0-webhook-modularization.md): Slack output helpers
extracted verbatim from bin/k3dm-webhook. No command behavior changes.
"""

import json
import re
import urllib.parse
import urllib.request

from webhook.config import SLACK_BOT_TOKEN, SLACK_CHANNEL_ID


def _slack_post(url, text):
    """POST a text message to a Slack incoming webhook or response_url."""
    if not url:
        return
    data = json.dumps({"text": text, "response_type": "in_channel"}).encode()
    req = urllib.request.Request(url, data=data,
                                 headers={"Content-Type": "application/json"})
    try:
        urllib.request.urlopen(req, timeout=10)
    except Exception:
        pass


def _post_slack_bot(text, thread_ts=None):
    """POST to Slack chat.postMessage API. Returns ts on success, empty string on failure."""
    if not SLACK_BOT_TOKEN or not SLACK_CHANNEL_ID:
        return ""
    payload = {"channel": SLACK_CHANNEL_ID, "text": text}
    if thread_ts:
        payload["thread_ts"] = thread_ts
    data = json.dumps(payload).encode()
    req = urllib.request.Request(
        "https://slack.com/api/chat.postMessage",
        data=data,
        headers={
            "Authorization": f"Bearer {SLACK_BOT_TOKEN}",
            "Content-Type": "application/json; charset=utf-8",
        },
        method="POST",
    )
    try:
        with urllib.request.urlopen(req, timeout=10) as resp:
            result = json.loads(resp.read())
            return result.get("ts", "") if result.get("ok") else ""
    except Exception:
        return ""


def _fetch_thread_context(thread_ts, limit=20):
    """Fetch recent messages from a Slack thread; return cleaned text or empty string."""
    if not SLACK_BOT_TOKEN or not SLACK_CHANNEL_ID or not thread_ts:
        return ""
    params = urllib.parse.urlencode({
        "channel": SLACK_CHANNEL_ID,
        "ts": thread_ts,
        "limit": limit,
    })
    req = urllib.request.Request(
        f"https://slack.com/api/conversations.replies?{params}",
        headers={"Authorization": f"Bearer {SLACK_BOT_TOKEN}"},
    )
    try:
        with urllib.request.urlopen(req, timeout=10) as resp:
            data = json.loads(resp.read())
        if not data.get("ok"):
            return ""
        lines = []
        for msg in data.get("messages", []):
            if msg.get("bot_id") or msg.get("subtype"):
                continue
            text = msg.get("text", "").strip()
            if not text:
                continue
            # Skip bot status lines (hourglass, checkmarks, progress noise)
            if re.search(r'^[⏳✅❌🔄⚠️]|^\*?k3dm\*?|^:hourglass', text):
                continue
            # Strip ANSI and excessive whitespace
            text = re.sub(r'\x1b\[[0-9;]*[mK]', '', text)
            text = re.sub(r'\n{3,}', '\n\n', text).strip()
            if text:
                lines.append(text)
        return "\n---\n".join(lines) if lines else ""
    except Exception:
        return ""
```

> The two inline comments inside `_fetch_thread_context` are copied verbatim from the
> original — do not add, remove, or reword any comment. `__init__.py` already exists from
> the config slice; do NOT recreate or modify it.
