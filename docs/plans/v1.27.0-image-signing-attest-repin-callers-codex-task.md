**Story:** image-signing CVE-loop closure (`v1.27.0-image-signing-cve-loop-closure.md`).
This activates the already-merged CI `cosign attest` slice
(`v1.27.0-image-signing-attest-codex-task.md`, infra PR #95, merge SHA
