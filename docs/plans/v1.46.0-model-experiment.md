## Design

Each child spec goes to a different implementer model, across codex (OpenAI) and agy (Gemini). Same spec rules, same
verifier (Claude, from `## Acceptance` only), same land gate. Waves respect dependencies and the 3-dispatch WIP limit:
wave 1 p2a + p3a; wave 2 p2b + p2c + p3b (after their parents land and proofs are captured); wave 3 p2d + p3c.

Combine review per plan, by a model that implemented no child of that plan: plan 2 by Fable (Neon implements p2b),
plan 3 by Neon. The reviewer reads the landed children together against the umbrella spec (seams, contract drift,
duplicated helpers) before the plan is marked done; `codex-dispatch combine` records the result.

## What is recorded per child

Wall time; tokens (from the run record); resumes/corrections needed; scope violations (files outside `## Files`);
first verify result; must_not red controls actually run and red on base; mutants caught; findings in Claude's verify and in
the combine review (severity); land rework; spec questions the model got wrong.
