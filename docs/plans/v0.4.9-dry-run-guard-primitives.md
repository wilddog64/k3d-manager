## Why

Downstream consumers (k3d-manager) need a shared, tested primitive to gate destructive/provisioning
side-effects behind `DRY_RUN=1` across cluster up/down paths. There is no such primitive today, so
`DRY_RUN=1` is silently ignored and "dry" runs really mutate state. This adds the primitive foundation-first
so the consumer can subtree-pull it rather than defining a divergent copy.

---

## Change 1 — `scripts/lib/system.sh`: add two helpers

Add immediately **after** the `_warn` definition (currently line ~1849, `function _warn() { … }`), before
`function _err()`:

**Exact new block:**
```bash
function _dry_run_active() {
  [[ "${DRY_RUN:-0}" == "1" ]]
}

function _dry_guard() {
  local _desc="${1:-}"
  shift || true
  if _dry_run_active; then
    _info "DRY_RUN: would ${_desc}"
    return 0
  fi
  "$@"
}
```

Semantics:
- `_dry_run_active` — predicate; success iff `DRY_RUN=1`. Use to gate multi-step blocks.
- `_dry_guard "desc" cmd args…` — wraps a **single** command; in DRY_RUN logs `DRY_RUN: would <desc>` and
  returns 0 without executing; otherwise runs the command and preserves its exit status.

## Change 2 — `scripts/tests/lib/system.bats`: cover both helpers

Add these tests (adapt the `load`/source preamble to match the existing tests in this file):

```bash
@test "_dry_run_active true only when DRY_RUN=1" {
  run bash -c 'source scripts/lib/system.sh; DRY_RUN=1 _dry_run_active'
  [ "$status" -eq 0 ]
  run bash -c 'source scripts/lib/system.sh; DRY_RUN=0 _dry_run_active'
  [ "$status" -ne 0 ]
  run bash -c 'source scripts/lib/system.sh; unset DRY_RUN; _dry_run_active'
  [ "$status" -ne 0 ]
}

@test "_dry_guard in DRY_RUN logs intent and does NOT execute" {
  sentinel="$(mktemp -u)"
  run bash -c "source scripts/lib/system.sh; DRY_RUN=1 _dry_guard 'create marker' touch '${sentinel}'"
  [ "$status" -eq 0 ]
  [[ "$output" == *"DRY_RUN: would create marker"* ]]
  [ ! -e "${sentinel}" ]
}

@test "_dry_guard outside DRY_RUN executes and preserves exit status" {
  sentinel="$(mktemp -u)"
  run bash -c "source scripts/lib/system.sh; DRY_RUN=0 _dry_guard 'create marker' touch '${sentinel}'"
  [ "$status" -eq 0 ]
  [ -e "${sentinel}" ]
  rm -f "${sentinel}"
  run bash -c 'source scripts/lib/system.sh; DRY_RUN=0 _dry_guard "fail" false'
  [ "$status" -eq 1 ]
}
```
