**Component:** Agent Dispatch and provider adapter; Hermes observer

## Problem
Agent retries, handoffs, nested dispatch, tool loops and model quota exhaustion may amplify a local failure into repeated work, resource exhaustion or uncontrolled billing. Unknown run outcomes cannot be interpreted as success or failure.

## Design
- Every run has durable run ID, parent run ID, coordinator and worker identity, retry ancestry, start/exit/land state, and effective policy version.
- Introduce configurable per-task ceilings for concurrent workers, depth, automatic retries, elapsed time, tool calls and *measurable* token/API spend. Example initial test profile: depth 1, two retries and an operator-defined spend cap; tune through evidence, not hardcode as universal limits.
- Enforce admission atomically across concurrent hosts using lease/fencing semantics; recheck active budget before each new worker/tool action. Fail closed on unavailable quota accounting for spending actions; report unknown vendor subscription consumption honestly.
- Circuit breaker detects repeated identical failure signatures, abnormal dispatch fan-out, expired lease and reentrant self-dispatch. Stop **new** execution, preserve active evidence/worktrees and notify operator; cancellation of an active mutating action follows its safety contract.
- No automatic model escalation that bypasses budget, privileges or operator approval. Coordinator handoff retains run ancestry, scope and remaining budget.
- Hermes/Grafana expose aggregated rejected/loop/retry/budget outcomes. Ledger stores high-cardinality IDs; Prometheus labels remain bounded.
- Read-only dry-run simulation before enabling enforcement.

## Files
- Existing dispatch lifecycle/budget adapter and durable event ledger.
- Bounded anomaly exporter and Grafana Agent Dispatch panels.
- Offline concurrency, crash-recovery and budget-fixture tests.

## Acceptance
1. Recursive worker spawn is denied with reason code and no new worker process.
2. Repeated failures stop at configured retry ceiling, with no lost artifacts.
3. Concurrent dispatchers cannot both consume one remaining slot/lease.
4. Quota exhaustion or coordinator replacement cannot reset the task budget.
5. Unknown outcomes remain unknown until independently reconciled; alerts do not claim token costs when unavailable.
6. Failure injection proves the breaker itself cannot trigger an unbounded recovery loop.

## Out of scope
Vendor-wide billing control guarantees, automatic subscription usage retrieval where unavailable, and unrestricted autonomous remediation.
