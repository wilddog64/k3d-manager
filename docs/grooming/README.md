# Release grooming

One file per grooming (`/release-groom`, Sunday afternoon and at each release cut): this week's dispatch queue and
must-do bugs, release order decisions (swaps into and out of the next release), idea decisions and capacity. Rules:
`docs/ideas.md`; the order itself lives in `docs/roadmap.md`. Replaced the weekly sprint plan (`docs/sprints/`) on
2026-11-08.
