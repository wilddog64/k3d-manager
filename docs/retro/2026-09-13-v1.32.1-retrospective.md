# Retrospective — v1.32.1

**Date:** 2026-09-13
**Milestone:** Security hotfix — clear Dependabot #9 / #10 on `main`
**PR:** #125 — merged to main (`062dd9ab`)
**Participants:** Claude, Codex, Copilot

## What Went Well
- Hotfix branched from `main` instead of shipping the in-progress v1.33.0 milestone; the only non-subtree change was the CHANGELOG.
- Every subtree pull was verified by containment (0 files outside `scripts/lib/foundation/`) and tree equality against the lib-foundation commit.
- The 4 BATS failures were proven pre-existing on untouched `main` in a detached baseline worktree before being called out of scope.
- Copilot's findings on vendored acg code were fixed upstream (lib-foundation #54), not patched in the subtree, then re-pulled into both branches.
- Dependabot #9 and #10 closed automatically on merge; 0 open alerts.

## What Went Wrong
- A subtree squash pull cannot cherry-pick, so the hotfix necessarily carried every lib-foundation change since `main`'s vendored version (v0.4.16/v0.4.17 ACG fixes), widening the review surface.
- Codex was denied `.git/index.lock` in lib-foundation hours after committing there successfully — the sandbox limit is intermittent; Claude verified and committed.
- An earlier Codex npm task placed a CHANGE.md entry under an already-released section; caught by a positive section assertion.
- The auto-mode classifier blocked a memory-bank commit worded around the enforce_admins change; resolved by asking the user rather than working around it.
- Gemini live smoke was not run (stated in the PR body).

## Decisions Made
- Hotfix from `main` (v1.32.1) rather than releasing v1.33.0 early.
- Stale BATS assertions fixed on v1.33.0 are deliberately not backported to the security hotfix.
- The local `lib-acg` clone is kept; archiving the GitHub repo is sufficient.

## Theme
Two Dependabot alerts on `main` lived in the vendored acg lockfile, and the fixes existed only on unreleased branches. Rather than ship v1.33.0 early, a patch release pulled lib-foundation into `main` alone. Copilot surfaced two real message bugs in the vendored code; they were fixed at the source in lib-foundation, re-vendored into both branches, and the hotfix merged with the alerts closed and `main` merged back into v1.33.0.
