## Process Rules Added

- **Release PR is a merge gate:** a normal PR (never draft), then CI, Copilot, Claude live smoke test (read-only, on the hub) and Claude scope check, all before merge (CHANGELOG Process; `docs/process/rules.md`).
- **LIVE-VERIFIED** is a recognized bug status alongside OPEN, LANDED and VERIFIED.
- **Independent verifier and blind two-reviewer process** documented in `docs/process/verification-and-review.md`.
- **Prompt-debt audit** (2026-11-15, `docs/process/prompt-debt-audit-2026-11-15.md`): dead instructions removed from CLAUDE.md, AGENTS.md and GEMINI.md.
- **Every CI run on the head SHA** must be green before a CI-green report (added after the one-run miss).
- **Dirused is tracked separately** (operator decision 2026-11-15): never assigned to a k3d-manager release or gate.

## Theme

Hub hardening and live feedback: the hub runs only promoted code, a dev vCluster gives a place to check before a promote, and the hub tells the operator when a CI-green commit is waiting. The lesson of this release is that the gates worked, but CI cost (22 minutes per run) and the single-run CI report slowed every merge.
