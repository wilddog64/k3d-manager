# Retrospective — v1.43.12

**Date:** 2026-10-31
**Milestone:** M5 hub release
**PR:** #153, merged to main (`bd68d6ff`)
**Participants:** Claude, Codex (Luna), Copilot

## What Went Well
- The M5 became the hub on 2026-10-31 through `make hub-new` and `make hub-cutover`, including the Hostinger
  ArgoCD hand-off, with a scale-based rollback that never deletes a registration.
- Three bugs found on release day were fixed inside the release instead of slipping a week: stage2 was
  retired, the CVE rebuild now clears the buildkit cache before dispatch, and the payment 401 was traced to
  the registry rejecting the classic PAT (fixed in payment #99 with `GITHUB_TOKEN`).
- The CVE fix was proven red on the pre-fix script and against five mutations (filter removed, token in
  argv, `for: 1d`, and both alert label filters).
- The curl stub for the cache API used key shapes captured from the real API, not invented ones.

## What Went Wrong
- **Four CI reds on PR #153 in one day**, at least three of which a local check would have caught in
  seconds; the last was a bare `! grep` that `bats_negation_lint.bats` rejects in 0.11 s. `land` ran only
  the task's own tests. Filed: `docs/bugs/2026-10-31-ci-reds-reproducible-locally-no-fast-gate.md`.
- **Wrong first diagnosis of the payment 401.** Claude called `PACKAGES_TOKEN` expired or revoked; the
  operator's token list showed it valid. The real signal was every layer `CACHED` on the last green run.
- **Wrong first root cause of the CVE loop.** The first bug draft blamed pinned libraries; the cause was the
  reused build cache.
- **stage2 never passed in its recent history.** Every earlier run was cancelled by a newer push, so its
  drift (OrbStack stopped, no Vault on the M2) stayed hidden until the label was added.
- Luna's promtool test was in no CI target, and its CHANGELOG entry went under `[Unreleased]`; both were
  caught in Claude's review.
- A refused land's test log is overwritten by the next attempt. Filed:
  `docs/bugs/2026-10-31-land-test-log-overwritten-and-refusal-has-no-count.md`.

## Process Rules Added
| Rule | Where |
|---|---|
| A 401 from a package registry: check whether the last green run was all `CACHED` before blaming the token | memory `reference_packages_token_expiry_image_build.md` |
| A new promtool test is added to `test-alertmanager-behaviour` in the same commit | this retro |
| A fast local gate runs before push and in `land` (v1.43.13) | `docs/bugs/2026-10-31-ci-reds-reproducible-locally-no-fast-gate.md` |

## Decisions Made
- stage2 and its runner lock are retired; remote e2e on the M2 is the live test path (operator, 2026-10-31).
- Copilot "Watch and fix" is not used on release PRs; it pushes unreviewed fixes (operator, 2026-10-31).
- The publish job of the Java services pulls GitHub Packages with `GITHUB_TOKEN`; order needs the same
  one-line change.

## Theme
v1.43.12 moved the hub to the M5 and made a new Mac a one-command setup. Release day turned up three old
faults that had been hiding behind caches and cancelled runs: a CI job that could not pass, a CVE rebuild
that replayed the old layers, and a token the registry had quietly stopped accepting. All three were fixed
before the merge. The cost was four CI round trips that a few seconds of local checks would have saved,
which is what v1.43.13 opens with.
