- **Spec defects were found at land time.** Fixture readers the spec missed (containment: two spec corrections, root-token: one) and machine-manifest readers for the stall A2 watcher. Each cost a resume.
- **Hermes E3 is not live-verified.** It needs a real CI unknown or degraded page, which has not occurred. The operator chose to merge without it; the bug stays open.
- **Containment E8 is not live-verified yet.** It can only run at the post-merge promote of `666b27b7`.
- **Argon found four P3 defects introduced by this release's own fixes:** stall DB fallback on a resumed agy run (`f3828ad9`), stall-watch E4 test asserts nothing about git failure (`c91b4409`), unseal filter hides errors on an empty shard (`dd7c18ed`), spec-intent accepts an empty `intent: []` (`d09d98f2`).
