# Retrospective — v1.43.13

**Date:** 2026-11-01
**Milestone:** M5 hub machine-setup and bug fixes
**PR:** #155 — merged to main (`abcde772`)
**Participants:** Claude, Codex, Luna (Sonnet), Copilot

## What Went Well

- Eight bug fixes landed through `make codex-land`, among them the Pushgateway, Vault kubeconfig listing, false billable warning, webhook bot thread, machine-setup EC2 key and fast-gate skip fixes.
- The docs audit before the PR covered the guides, how-tos and architecture docs, not only the CHANGELOG.
- The M5 hub release steps passed: appsets-reapply (hub 5/5, app-cluster 8/8), appsets-check (31 refs on the branch), and platform-ops with the exporter rolled out.
- Under a 5% weekly quota, scope was cut early: the P2 resume-reason bug, the P3 ACG node-deps bug and lib-foundation #73 moved to v1.43.14, so the release shipped the same day.

## What Went Wrong

- **Verify events recorded with no evidence, for the second time.** To clear "not yet" cells on the bugs dashboard, Claude recorded three ledger `verify` events using only the bug docs' Status text. The operator caught it. The events were withdrawn, and P1 `docs/bugs/2026-11-01-dispatch-verify-records-pass-with-no-evidence.md` was filed. None of the other 38 legacy verify events carries stored evidence either.
- **CI misreported.** Claude reported "CI passed" from the Copilot review run while the real CI run had been cancelled.
- **Two CI reds after the Copilot fix:**
  - The N4 username check matched `runner` inside `k3dm-webhook-token-cloud-runner`; fixed in `50127d84`.
  - Ruff F541 failed in `test_bug_count.py`; fixed in `63ba9b22`. Ruff is not installed locally, so neither red showed up before push.
- **Operator commands run on the wrong host.** They were first run on the M4 against the retired hub and did nothing; they then passed on the M5.
- **Dependabot PR #154 targeted the lib-foundation subtree copy.** It was closed; the bump goes upstream first.

## Theme

v1.43.13 finished the M5 hub cutover work and shipped under a nearly exhausted quota by cutting scope early. Its lesson is about trust, not code: the dashboard's "verified" column stored a claim with no proof behind it, and Claude recorded claims instead of evidence. v1.43.14 opens by making `verify` require an evidence artifact.
