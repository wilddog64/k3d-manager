# Retrospective — v0.4.18

**Date:** 2026-09-24
**Milestone:** credential-test observability + headless Pluralsight auto-login fix
**PR:** #55 — merged to main (`2f244ee4`); stamped `v0.4.18`; tag + release live
**Participants:** Claude, Copilot

## What Went Well

- **Observability exposed the real defect.** The new `acg_session_check.js` instrumentation added diagnostic markers (`ACG_LOGIN_FIELDS_MISSING: email=missing password=filled`) per stage. Those markers revealed that the headless login form was fully rendered and visible, but the CSS selector was matching nothing—exposing the root cause in its first run. This converted three successive wrong diagnoses into the actual bug without requiring multiple test cycles.
- **Selector fix was verified in Playwright's own engine.** After adding the ` i` flag for case-insensitive matching on all name/id arms, a direct `count()` call in Playwright confirmed OLD `count()`=0 → NEW `count()`=1. A native `document.querySelectorAll` check would have claimed success falsely—Playwright implements its own CSS parser.
- **Timeout refactoring was mutation-gated before release.** `_robustClick` was rewritten to use an explicit bounded `waitFor` in place of `locator.evaluate()` which inherits Playwright's 30s default. The timeout test was then run in isolation, producing exactly 1 failed / 39 passed—confirming only the new timeout assertion failed, proving the refactor was necessary and correct.
- **Copilot's two real findings were fixed before stamp.** (a) `waitFor` now has an explicit timeout matching the rest of the module's `FIELD_TIMEOUT_MS` budget. (b) A duplicated `## Outcome` section in the bug doc was caught and removed.
- **Dependency lockfile bumps cleared two high-severity npm audit findings.** `brace-expansion` and `js-yaml` updates resolved CVSS issues without breaking tests.
- **Package identity was cleanly renamed.** `lib-acg` → `lib-foundation-acg` (metadata only) with no functional change, aligning the npm scope to the repo.
- **Gates all passed.** `npm run check` clean; jest 7 suites / 40 tests; `make bats` plan 1..138 with 138 ok / 0 not ok / 0 skips / no index gaps. CI verified per-job (`shellcheck`, `bats`, `acg (node)`) on head SHA `8986227`.

The artifact was chased rather than dismissed as a measurement error, costing investigation cycles.
- **Duplicated Outcome section was self-inflicted.** The bug doc was appended to in a prior edit without checking for an existing section, introducing the duplicate before Copilot caught it.
- **CHANGE.md was still marked [Unreleased] at PR time.** The heading had to be promoted to `[v0.4.18] — 2026-09-24` during pre-flight checks, which should have been done in the final commit of the PR branch.

## Process Rules Added

| Rule | Where | Why |
| ---- | ----- | --- |
| Instrument stages with diagnostic markers before theorizing about any single one | observability | Generic symptoms hide the real defect; add per-stage markers (e.g., `FIELD_MISSING: field=status`) that let you see the exact call state where it breaks |
| CSS attribute VALUES are case-sensitive; Playwright has its own CSS parser | browser testing | A native selector check proves nothing about `page.locator(...)`—verify flags in Playwright's own engine with `count()` |
| Timeout refactors need mutation-gating: replace the key line and re-run in isolation | testing | Proves the new code is necessary and correct: only that one test should fail before the fix and pass after |
| CHANGE.md headings must be versioned and dated before the PR is finalized | documentation | Prevents pre-flight churn; `[v0.4.18] — 2026-09-24` must land in the final commit, not added post-merge |

## Decisions Made

- **Deferred: unifying the two `_robustClick` copies.** The function appears in both `sandbox.js` and `acg_restart.js`. The version in `sandbox.js` swallows errors with `.catch(() => {})` while `acg_restart.js` does not, so unifying them changes the live sandbox-provisioning path. This requires a live sandbox to verify for correctness and is deferred to the next Tier 2 e2e round.
- **K3DM_ACG_REQUIRE_CREDENTIALS is the new fail-closed validation.** Any caller that needs ACG credentials must set this env var before loading the module. The new `acg_session_check.js` respects it as a required check.
- **ACG_SESSION_OK marker now reports the auth path.** Callers can parse the marker for `path=` to understand which login method succeeded. The emitted values are exactly `existing-session`, `auto-login` and `manual-login`; a gate that must prove *unattended* login should accept `auto-login` alone, since `manual-login` means a human signed in during the run.

## Theme

Observability isn't just logging—it's **failing gracefully with precise diagnostics**. The headless Pluralsight login had been silently broken for an unknown number of releases because the only feedback was "login timeout" on a form that looked rendered to the naked eye. Adding per-stage markers exposed that the real issue was CSS case-sensitivity in Playwright's parser, not a timing or visibility problem. The fix—adding the ` i` flag—was a one-character change, but it required the diagnostic infrastructure to find it.

Copilot's review brought two real catches (timeout boundary and document hygiene) and three measurement artifacts that reinforced the rule: when generic symptoms match multiple hypotheses, instrument the stages first, not last.
