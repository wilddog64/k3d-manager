## What Went Well

- **Clean 2-finding Copilot round on PR #122** — both real bugs in `preflight.py`, fixed with +2 regression tests (suite 33 passed):
  - (1) verdict was bound to the single newest Actions run (`per_page=1`→`30`); now samples the 30 most recent to avoid transient failures triggering scope failure on a legitimate recent-run hit.
  - (2) write-scope probe misread empty/transport-error output as write=true; now requires non-empty output before classifying as write-capable.

- **Correctly nailed the write-probe nuance:** a write-capable PAT still returns non-zero rc from `rerun-failed-jobs` against a successful run (business-logic error "cannot be retried"), so scope classification keys on absence of `"resource not accessible"`, never on rc.

- **Token-expiry advisory correctly designed as a STANDALONE once-per-day Slack advisory, not a correlator sensor** — the correlator is >=2-degraded, edge-triggered, so a lone signal would be swallowed. The advisory fires independently, once per day, with the token expiry header deduped per calendar day via `state`.

- **CodeQL `str.replace` redaction trips clear-text-storage** — correctly triaged as a false positive (the printed report holds only booleans + the literal "pat"; the token flows only into the subprocess env) and dismissed with a documented rationale (alert #21), flipping the PR check green.

- **CI green on every head; enforce_admins disabled proactively at merge-ready** — no last-minute surprises on merge day.
