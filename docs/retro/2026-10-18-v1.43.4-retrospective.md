## What Went Wrong

- PR #145 CI was cancelled three times after the cluster_down test ran. The root cause was in `cluster_down_acceptance` setup: `chmod +x bin/*` followed the `bin/bash` symlink to root-owned `/usr/bin/bash`, which fails with EPERM as non-root. The setup failure then reached the teardown, which ran `kill "${SLEEP_PID:-0}"`, so an unset SLEEP_PID became `kill 0` and killed the whole process group. Fixed by creating the symlink after `chmod` and guarding the teardown so a setup failure surfaces as a red test.
- The hermes poll tests never stubbed the new `_publish_cni_ipam_metrics` (added in v1.43.4). Each poll ran `bin/k3dm-cni-ipam-metrics`, which ssh'd to Hostinger and pushed to the hub from a laptop. The CI pytest tripwire blocked 16 ssh calls. Fixed by stubbing both fixtures and guarding the Pushgateway URL in conftest.
- An earlier PR #145 CI run went red on `f60c598f` with five rotted suites (watchdog CNI stub and bare-`!` lint, acg stub versus lib-foundation v0.5.4 flags, a DR freshness fixed date, and the bugs table Live evidence column). Fixed in `8d8dca19`.
- The Dependabot auto-merge bug was left OPEN after its fix (`46b8632b`) had landed, and had to be corrected to FIXED. Its live proof is still pending the next weekly Dependabot auto-merge.
- Basket PR #52 merged on 2026-10-18 at 12:51Z by github-actions[bot] before the fix, with no Go CI run. That was the last pre-fix sample.
