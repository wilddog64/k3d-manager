# Retrospective — v1.43.8

**Date:** 2026-10-25
**Milestone:** Release-tracking and ops-routing release
**PR:** #151 — merged to main (`6974f426`)
**Participants:** Claude, Luna (Codex), Copilot, operator

## What Went Well

- **Four plans landed the same day they were dispatched.** Luna landed release duration (`8e0e9078`),
  Slack status-channel routing (`76fffbe4`), the weekly hub snapshot (`97ed4977`) and Plans-table
  waves (`ea9638cc`). Claude reviewed each one and fixed small review defects itself before
  recording the land, following the week-of-10-26 trial.
- **Claude split the release before it overflowed.** The Hostinger public-path plan could not start
  before the 10-29 rebuild, so it moved to v1.43.10 as plan 5 instead of holding v1.43.8 open.
- **The P3 bug went from report to live-verified in one session.** The Bug Tracking Release row
  ignored Manual mode (`c567cc68`). The operator's screenshots were the E2 evidence. The review
  caught that Luna's Manual arm listed every release under **All**, which the acceptance block
  forbids.
- **Copilot found no issues** in a 39-file release PR.

## What Went Wrong

- **Land tests missed suites that read the touched dashboard, twice.** Release duration landed with
  3 tests red in `agent_dispatch_dashboard.bats` (fixed in `f5076dfd`). Claude's own fit change
  `56f0007d` then gave eight Per spec columns a second, width-only override, which turned 2 tests
  red in `test_dispatch_metrics.py`. Release prep caught it, fixed in `e535415a`.
- **CI lint failed on the release PR.** `ea9638cc` left an unused `info` list in
  `bin/k3dm-vectordb-metrics` (ruff F841). The local gate did not catch it because ruff is not
  installed on the Mac, and `make lint-python` exits 2 without it. Fixed in `5497ba01`.
- **Bug scan lag looked like a regression.** A FIXED bug showed Open on the dashboard because its
  push landed 6 seconds after a 300-second scan finished. It cleared on the next scan.
- **The roadmap had been stale since v1.29.0.** The README linked the archived v0.8–v1.0 plan, and
  `docs/roadmap.md` still named v1.29.0 as the active milestone. The operator noticed during release
  prep. Fixed in `2d7f032e`.
- **The documented Copilot review request did not register.** The REST call returned an empty
  reviewer list. `gh pr edit --add-reviewer @copilot` worked.

## Theme

v1.43.8 made releases measurable: how long each one took from first dispatch to merge, which plans
can run together, and which depend on or overlap others. It also scheduled the hub snapshot and sent
system noise to the status channel. The code landed quickly. Most of the friction came from gates
that tested less than they appeared to: land tests that skipped suites reading the same dashboard,
and a lint step that cannot run on the Mac. Both were caught before merge, by release prep and by CI.
