Live sheds and cluster restart proved the fixes' efficacy.

- **Load-shed observability toggle built.** `make monitoring-pause` / `make monitoring-resume` provides a two-controller reversal mechanism (app-level patch + appset ignore directive) that durably scales the observability stack to zero and back without sync deadlock.

- **Copilot review process refined.** Thread resolution (not just reply), inline comment sweeps, and pre-PR CI gates now standard. Three finding categories: critical (block until fixed), false-positive (document, don't fix), and architectural standing markers (CodeQL alerts #19/#20, left open as deliberate gaps).

## What Went Wrong

- **BATS test `webhook.bats` #295 asserted deliberately removed behavior.** Commit `384b0202` removed the `keycloak-admin-secret` fallback path, but the BATS test was never updated. CI passed between the change and PR #127 because the test suite was not run — root cause: no CI gate between the behavior change and the PR. Fixed in `c40924d1` by rewriting the test to assert the current contract (`keycloak-secrets` / `KEYCLOAK_ADMIN_PASSWORD` / `admin-cli`) plus a disappearance gate for the old path.

- **`bin/cluster-status-summary` EXIT trap referenced `${_tmp}` five lines before assignment under `set -euo pipefail`.** Copilot surfaced this in review TEXT ONLY (a narrative finding, not an inline comment), so a sweep of `gh pr view 127 --json comments` alone would have missed it. Fixed in `c40924d1` by reordering assignment before the trap.

- **No release tag created.** CHANGELOG.md remained at `[Unreleased]` — no versioned entry `## [1.34.0] - 2026-09-17` was present to trigger tagging. Decision: skip v1.34.0 release tag creation; start v1.35.0 from merge SHA 978ea60f without a formal tagged release.

- **HTTP/2 failure-rate observability deferred.** Tier 1 E2E currently cannot distinguish HTTP/1.1 from HTTP/2 failure rates; this awaits protocol/version labels from Tier 2 observability coverage, extending the dashboard feature gap into v1.35.0.

- **Five-plan milestone cap is full.** v1.34.0 reached the design limit: `hermes-scheduled-e2e`, `hermes-sms-pager`, `slack-k3dm-make-command`, `hermes-scheduled-status-triage`, and `e2e-grafana-trends-and-drilldown`. v1.35.0 opens for the next spec batch.

## Process Rules Added

- **CI gate placement matters.** A BATS test regression can hide in dead CI until it merges. Enforce: test suites run on every commit, even when the change is "obviously unrelated" (the behavior it tests may have changed in an earlier commit not yet merged).

- **Copilot narrative findings are binding.** Text-only review comments carry the same weight as inline comments. Sweep both `gh pr comments` and the full review text before merging. Inline comments highlight scope; narrative catches architecture and sequencing issues.

- **Hermes autonomy is no longer speculative.** Proof-of-concept on 2026-09-16 validates the design. Future work: scale from ad-hoc scheduling to policy-driven approval gates (Slack pull model with 24h re-auth).

## Decisions Made

- **CodeQL alerts #19/#20 deliberately left OPEN.** Both are pre-existing (filed 2026-09-03), not required checks, and represent a verified false positive in the `_register_secret` fetch-scoped taint path. The alerts stand as a standing marker: until the gap (inability to scrub secrets arriving via subprocess output) is closed architecturally, the alerts serve as a visible TODO. Decision: do not dismiss; track via auto-memory reference.

- **v1.34.0 closed at the 5/5 plan-doc cap.** The design intention is strict: five specs per release. v1.34.0 reached the cap; v1.35.0 opens for new specs. Split before a sixth spec to maintain focus and predictable scope.

- **Release tag skipped due to missing CHANGELOG version heading.** CHANGELOG only had `[Unreleased]`, not a versioned entry `## [1.34.0] - 2026-09-17`. Decision: skip tag creation; v1.35.0 branch traces from merge SHA 978ea60f. If v1.34.0 release tag becomes necessary, it can be created retroactively at the merge SHA.

- **ApplicationSet reapply is a required release step.** v1.34.0 config is inert until the ApplicationSets are reapplied at `k3d-manager-v1.34.0` branch. Decision: commit reapply procedure to release checklist (both hub and ACG variants; verify with `argocd_check_values_branch`).
