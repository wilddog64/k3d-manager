## ACG and e2e

- ACG sandbox expiry/rebuild work established that cluster, Vault/ESO, data layer, and application services must converge in order. Missing Services/secrets after rebuild can make dependent pods fail on DNS or credentials.
- Tier 2 e2e gained sandbox preflight, provisioning, cleanup, result publication, no-wait cleanup deletion, and a 420-second hub Application settle wait. A prior `kubectl config get-contexts | grep -qx` SIGPIPE race was fixed and mutation-tested.
- Live e2e evidence belongs in bug docs with run ID, environment, scenario, commit, and acceptance IDs. `docs/issues` holds detailed terminal findings; `docs/bugs` is required for Bug Tracking dashboard capture.

## Dashboards and observability

- Bug Tracking dashboard metrics come from `docs/bugs` and require parseable `Filed`, `Status`, `Priority`, and release/branch metadata. `LIVE-VERIFIED` additionally requires live evidence and, for new records, a Fix commit.
- PR Checks uses Hermes Pushgateway metrics and the `k3dm-pr-checks` dashboard. The repo filter is based on `k3dm_pr_checks_open_prs`; GitHub read health must be interpreted before treating empty data as a collector failure.
- Dashboard screenshots that reveal a display defect should get a P3 `docs/bugs` record with the exact panel, current JSON/config, screenshot symptom, expected behavior, and live acceptance.

## Security, provider, and automation decisions

- Dependabot automerge moved to GitHub App-token issuance so merges trigger main CI; prove mergedBy and resulting image/build runs.
- Image pins are immutable digests; `make image-pin-drift` reports drift without silently changing pins. CVE remediation must distinguish source pins, live overrides, and deployed image evidence.
- Provider teardown must preserve the hub when requested, deregister sandbox applications safely, and report cloud teardown failures rather than claiming success.
- Live commands involving clusters, Keychain, Cloudflare, or external credentials remain operator/Claude-owned unless explicitly requested as read-only diagnostics.
